### 判决

**H1 证实——"W_a 断点"在两个 backbone 上都真实存在**（rel>0.1 且视觉能量占比 < 3×基线）：

1. **两个模型都是 untied → W_a 非恒等**（rel≈1.15/1.19）。"断点是伪问题（tied 退化）"的可能性被排除。
2. **视觉 token 与文本嵌入流形完全正交**：能量占比**精确等于随机基线**（0.060 vs 0.062、0.071 vs 0.071），最近邻 cos≈0.08。**projector 根本没有把视觉对齐到文本嵌入流形**——"projector 已对齐、照搬无害"的乐观假设被排除。✅ **阳性对照已补**（[Q&A/03](../Q&A/03-missing-positive-control-in-card1.md) E4，2026-08-03）：文本自谱占比 0.187-0.398（3.0-5.6×基线）、文本互邻 cos 0.24-0.35（视觉到文本的 3-4 倍）→ **"两个世界"方向保留、量化修正**：薄饼为中等厚度（top-256 解释 19-40% 方差），准确表述="视觉对文本主子空间偏好为随机水平（LLaVA 系）或弱（Qwen3-VL 0.108=1.7×基线），文本自身集中度为其 1.7-5.4 倍"。
3. ⭐ **推翻此前调研预判**（"W_a 是次要风险，repo 默认单位阵"）：默认配置（I+模长归一）产出的潜在思维与模型见过的任何输入**近乎正交**（cos 0.06），而真 W_a 能拉回输入流形附近（LLaVA cos 0.71）。**W_a 在 VLM 上可能不是开关，是必需品** → 卡 3 的 XWa 臂升级为关键对照。
4. 连带发现：视觉 token 以 **43-46 倍**于文本嵌入的模长直接进入 LLM 且工作正常 → LLM 可接受的输入空间远大于文本嵌入流形；LatentMAS "模长归一到文本平均"对视觉信息可能过于保守。LLaVA 视觉模长 std=51 说明存在巨模长离群 token（与 massive-activation 文献 2402.17762/2503.03321 一致）。

## 卡 2 — KV 前置数值等价 + M-RoPE 接管（H2/H3）✅ 已完成

### 实验设置（P1 / P2 定义）

- **P1（金标准）**：`[A 段(图+指令) ; B 段(纯文本)]` 拼成一条序列**一次性前向**——信息齐全（input_ids + image_grid_thw 在场），其位置计算定义上即正确答案；期间 hook 抓下内部 position_ids 矩阵备用
- **P2（LatentMAS 机制）**：A 段单独前向拿 `past_key_values` → B 段带 past 续算。各变体只有 **B 段位置来源**不同：(a) 让 HF 自己猜；(b) 手动 `arange(past长度…)`；(c) 从 P1 抓的矩阵里**切出 B 段对应列**显式传入（"金标准 3D 位置切片"，详见 [Q&A/02](../Q&A/02-why-append-works-in-text-but-breaks-in-multimodal.md)）
- 下表 **max|Δlogit| 与 top-1 一致率均为 P2 各变体相对 P1 的 B 段 logits** 之差/一致度——P2≈P1 即"KV 前置无损"成立
- 注意：P2c 的**取数程序**（重跑全序列再切片）非实战方案，但其所需**信息**可实战获得——A 段前向时位置本就被正确算出，记下 max 坐标即可；实战版=B1 的 MRopeTracker（自行记账，与切片逐位一致），详见 [Q&A/02](../Q&A/02-why-append-works-in-text-but-breaks-in-multimodal.md) 追问修正

### 数字

**LLaVA-1.5-7B**（1D RoPE；A 段 = 图+指令 609 token，B 段 = 纯文本 16 token）：

| 变体 | max\|Δlogit\| | top-1 一致率 |
|---|---|---|
| P2a 什么都不管 | 0.31 | **1.000** |
| P2b 显式连续位置 | 0.31 | **1.000** |

（0.31 为 bf16 下"批量 prefill vs 带 cache 续算"两条 kernel 路径的正常残差；纯文本 fp32 对照为 8.45e-05。top-1 完全一致。）

**Qwen2.5-VL-7B**（M-RoPE；A 段 177 token 含 144 视觉 token）：

| 变体 | max\|Δlogit\| | top-1 一致率 | B 段实际位置 |
|---|---|---|---|
| P2a 什么都不管（LatentMAS 现状） | **33.0** | 0.75 | **从 0 重启** |
| P2b 天真连续 `arange(177…)` | **19.3** | 0.94 | 177 起（错） |
| P2c 金标准 3D 位置切片 | 1.6 | **1.000** | **45** 起（对） |

**latent-step（inputs_embeds 续算）实际位置**：期望 177/178/179，实测 **[0,0,0] 三步三轴全塌**——此前用随机初始化小模型探到的坍缩，在真实 Qwen2.5-VL-7B 权重上复现。

### 判决

- **H2 证实（LLaVA）**：逐层 KV 前置在 1D-RoPE VLM 上**原生数值等价**，不需要任何位置处理。**主实验台锁定 LLaVA。**
- **H3 证实（Qwen）**，且比预期深一层：
  - 不管位置 → B 段位置从 0 重启，max|Δlogit|=33，灾难性且**静默**；
  - **天真连续位置也错**：M-RoPE 位置空间是**压缩**的——177 个 token 的最大位置只有 44（图像按 2D 网格占位），正确续位是 45 不是 177。**"记得传位置"不够，还得会算**；
  - 用金标准 3D 位置切片可完全修复（top-1 100%）→ 机制可救，修复路径 = 复刻 `get_rope_index` + rope_deltas 偏移。
- 这组数字（33.0 → 19.3 → 1.6/100%）是**四篇已有多模态 latent MAS 论文都没写过的技术点**，可直接进论文 method/analysis 节。

### 三个超出预期的发现

**① 盲 agent 打平了亲眼看图的 agent**：X=89.0% vs U=88.3%。A2 从未见过图像，只凭 A1 传来的 KV 作答，与自己直接看图**无差别**（甚至略高——U 的 prompt 里没有 A1 那句"仔细看图"的指令，语境略有差异）。

**② 安慰剂臂的行为本身就是内容传输的证据**：Xshuf=69.6% 高于 L=47.3%，乍看有"占位效应"，但看回答分布——Xshuf 的回答 74.8% 是 "no"（745/996），而 L 是 66.5% "yes"。即 **A2 在诚实地读"错误的图"**：被问"图里有 X 吗"而 KV 来自另一张图时，X 多半确实不在那张图里，答 "no" 是对错图的正确回答（POPE 的 no 类问题恰好占一半 → 69.6%）。这不是安慰剂，是**通道在传真实内容的反向证明**。

**③ W_a 反转 → 质心塌缩（与卡 1 对照最有意思的一条；经三轮探针逐层修正）**：

- 卡 1 说：默认 I+归一的 latent 与输入流形正交（cos 0.06），真 W_a 拉回流形（cos 0.71）→ 曾推断"W_a 是必需品"
- 卡 3 说：**默认 I 的 X 臂好好的（89.0%），真 W_a 的 XWa 臂 1000/1000 全部"空输出"**

**"空输出"的机制**（探针 `probe_xwa_ids.py`，打原始 token id）：模型并非不生成——**首个 argmax 恰好是 EOS**（生成序列 = `[2]` = `</s>`），`generate` 按规则停止，`skip_special_tokens` 剥掉后显示为空串。softmax 永远有 argmax——它就是结束符。

**Wa-latent 到底指向哪**（探针 `probe_padrows.py`，三层修正后的最终版）：

| 量 | 值 |
|---|---|
| LLaVA tokenizer 词表 | 32002（Llama 32000 + `<image>` + `<pad>`） |
| 嵌入矩阵行数 | 32064（GPU 对齐补到 64 的倍数）→ **62 行填充行** |
| 填充行结构 | 两两 cos 0.9995、与全体真 token 均值向量 μ 的 cos **0.9997** —— HF resize 的 mean-init，**62 行全部 ≈ 质心 μ** |
| step0 Wa-latent vs **μ** | **cos 0.699** ← 真正的信号 |
| 其真 token top-5 最近邻 | `<pad>`(0.700)、`<image>`(0.697)、▁During(0.27)、▁Looking(0.26)… |
| I-rollout 的 latent 最近邻 | 全是 cos≈0.06 的随机碎片（mult/AN/kor/…） |

**结论链**：
1. $W_a$ 是对全词表的最小二乘回归 → **回归解向均值收缩** → h@Wa 塌向嵌入质心 μ（实测）；
2. 质心附近的"居民"恰好是 mean-init 未训练的 `<pad>`/`<image>`/62 填充行 → A2 的回答槽里塞了 10 个"长得像 `<pad>` 的伪 token"（实测）；
3. 回答位被 pad 样信号占满 → 首 token argmax = EOS（**此环为推断**，可确证的是 1000 题稳定复现）。

**修正后的总结论**：在 VLM 上，m 步潜在思维两种配置都没有贡献载荷——默认 I 配置产出与全词表正交的**惰性噪声**（A2 无视，X≈Xprm 证实）；W_a 配置因**质心塌缩**产出 pad 样有害信号（触发 EOS）。**M1（潜在思维）在视觉感知任务上贡献为零，全部有效载荷在 M2（KV 传递）搬运的图像+prompt KV 里。**

> 机制澄清（回应追问）：latent 步喂进模型的是**投影后的连续伪 embedding 本身**（`models.py:331-346` 的 `inputs_embeds=latent_embed`），**从不吸附到最近邻 token**。上表的 cos/最近邻是诊断量尺，不参与前向。

**追问实验②：Wa 翻译后的伪 embedding 还保留样本信息吗？（`probe_wa_distinct.py`，Qwen3-8B，8 个语义迥异 prompt）**

> 符号：h=末层隐状态；v_I = h 只缩模长（默认配置，方向与 h 相同故并作一行）；v_Wa = h 乘 W_a 再缩模长（论文配置）；μ=质心（全部真 token 嵌入的平均向量）。两两 cos = 8 个 prompt 的该类向量互相之间的方向相似度（量样本区分度）；去质心 = **正交投影去除** `v − (v·μ̂)μ̂`（每个向量减掉自己在质心方向上的投影、结果与 μ 垂直——**不是** `v−μ` 向量减法，后者只是平移原点、删不掉方向），检验"共享成分是否只是 μ 方向"：删后相似度不降 → 共享的是更大的方向子空间。

| | 两两 cos | cos(μ) | 去质心后两两 cos |
|---|---|---|---|
| 原始 h / v_I | 0.848 [0.77,0.90] | 0.027 | 0.848 |
| v_Wa | **0.889** [0.65,0.97] | 0.398 | **0.889** |

三个发现：①**原始 h 本身挤在 0.85 的窄锥里**（LLM 各向异性）——"意义"从来只住在 15% 的方向差里，刻度必须按"样本区分度"来定；②Wa 翻译保留约 **73%** 的区分度预算（区分度=1−平均两两cos：0.152→0.111，比值 0.73；表中 [min,max] 为 28 对里最不像/最像的一对——**min 0.649 是"没有全塌"的最硬证据**：若 8 个向量已合并，任意一对都应 ≈0.99）——**信息被降级，没被销毁**。注意糊得不均匀：max 0.971 说明有一对已近乎重合，"73%"是平均账、个别样本对损失远超 27%（A3 扩样本的动机之一）；③修正"塌向质心"的说法：去质心后 Wa-latent 相似度不变（0.889）→ 它们共享的公共方向**不只是 μ**，是回归解偏爱的一小片方向（μ 只是地标之一）。**几何上有信息 ≠ 被模型读取**——行为（无视/中毒）与载荷（X≈Xprm）证据均为阴性。边界：n=8、单模型、step-0（正式版升格为 Phase 2 实验 A3，文本与 VLM 都测）。能量分解口径：沿质心方向能量占比 = cos²θ（正交分解+勾股：cos 0.6 → 36%/64%，即 3-4-5 三角形）。

**追问实验③：乱码赢家是不是"质心居民"？（`probe_who_lives_near_mu.py`，Qwen3-8B 全词表）**——是。全词表 cos(row,μ) 均值 0.131；rollout 三个乱码赢家 cos(μ)=0.386/0.555/0.341，其中 `×ķÖ` 是**全表离质心第 1 近的行**；离质心最近的 top-15 清一色欠训练碎片（希伯来/韩文/乐谱符号）。**统一原理**：v 塌向质心 → 最近邻赢家=住得离质心近的行 → 那里永远是最没被训练的行（与 SolidGoldMagikarp/undertrained-token 文献吻合）。两模型的分岔只在荒地上盖了什么：LLaVA 有 mean-init 占位房（cos 0.9997，强匹配 0.70，空白语义→中毒）；Qwen 只有零星乱码棚户（0.33-0.56，弱匹配 0.31-0.42→被无视）。

**几何塌缩有、行为毒性无**。差异的候选解释【推断→部分坐实】：毒性需要"塌缩方向有强匹配+空白语义的居民"两条叠加——LLaVA 的填充行是 HF resize 的 **mean-init**（62 行≈质心、`<pad>`/`<image>` cos 0.70 强匹配）；Qwen3 的 267 行填充行是**随机 init**（与质心 cos 0.0016，正交），质心附近只有 cos 0.31-0.42 的弱匹配乱码 → 被无视。**EOS 惨案有一半是 LLaVA 词表扩充方式的工程巧合，非 W_a 的普适必然。** 这同时解释了：论文在文本上没发现问题（行为无害、分数看不出）、README 把 realign 降为"按任务开关的超参数"（噪声级扰动本就时好时坏）。边界：单 prompt 单模型，未测任务分数。

## Phase 1 总判决

**五个假设全部解决，training-free 多模态 LatentMAS 的核心机制（M2：KV 工作记忆传递）在 1D-RoPE VLM 上成立，且效应量巨大。**

| 假设 | 判决 | 关键数字 |
|---|---|---|
| H1 $W_a$ 断点 | ✅ 真实存在 | rel‖Wa−I‖≈1.15/1.19；视觉与文本流形正交（能量占比=随机基线） |
| H2 KV 前置等价（LLaVA） | ✅ 原生成立 | top-1 100%，Δlogit 0.31（bf16 噪声级） |
| H3 M-RoPE 必须接管（Qwen） | ✅ 证实 | 不管=33.0/75%、天真管=19.3/94%（位置空间压缩！177 token→位置 45）、正确管=1.6/100%；latent 步位置 [0,0,0] 坍缩 |
| **H4 视觉信息可达** | ✅✅ **证实** | **X−L=+41.7pp，p=8e-77；X 追平上界 U** |
| **H5 非安慰剂** | ✅ **证实** | X−Xshuf=+19.4pp，p=6e-43 |
| 附加：X>T | ✅ 显著 | +2.8pp，p=5.6e-3——**latent 通道显著优于文字通道** |
| 附加：载荷定位 | 意外发现 | **latent 步贡献为零**（X≈Xprm=89%；Xlat 单独=空输出；XWa=有害） |

### 对下一步的直接含义

1. **项目成立，可以进卡 5（完整 4-agent MAS 主表）**——H4/H5 双双大幅通过，止损线一个都没触发。
2. **方法定型**：VLM 版 LatentMAS = **纯 KV 前置（M2），砍掉 m 步潜在思维（M1）**。这既省算力（每 agent 少 m 次前向）又有数据支撑（X≈Xprm）。"砍掉 M1"本身是与原论文的清晰差异点。
3. **W_a 在 VLM 上的正确表述**：不是"必需品"也不是"伪问题"，而是**"对 rollout 有害、对通道无用"**——卡 1 的几何观察（拉回流形）与卡 3 的行为观察（触发 EOS）合起来才是完整故事。四篇已有论文没有一篇有这组测量。
4. **Qwen 系解锁件** = M-RoPE 位置接管模块（修复路径已验证：金标准 3D 位置切片 → top-1 100%）。
5. **效率论证注意**：Xprm≈X 意味着实际要传的 KV = A1 的 prompt 段（609 位置，其中 576 是图像）。与 Text-MAS 相比省掉的是 A1 的自回归解码 + A2 重读描述；与"A2 直接看图"（U）相比省掉的是 A2 的整个视觉编码前向。效率表要按这三个口径分开报（卡 6）。

### 诚实边界（写论文前必须记住的）

- 只测了 **POPE（对象存在性 yes/no）× LLaVA-1.5-7B × 单对 agent**。POPE 是感知型任务，图像 KV 直接携带答案；**推理型任务（GQA 组合推理 / MMMU）上 latent 步是否仍然无贡献，未测**。
- X 略高于 U（+0.7pp）在 discordant 检验下并不显著，不能宣称"超过上界"。
- Xshuf 的 no 偏置解释是观察性推断，若要写进论文需按图配对做定向验证。
- m 只扫了 10（与 0 等价的 Xprm）。m∈{5,20,40} 的趋势未跑——但既然 m=10 贡献为零，优先级降低。
