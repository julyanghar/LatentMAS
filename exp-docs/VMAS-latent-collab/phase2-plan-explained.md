## §0 比喻体系与全部登场角色（自足介绍，不省略）

### 0.1 考试比喻：谁在传什么

想象一场考试，两个学生：

- **A1（看图的同学）**：拿到考卷上的图，仔细看了；
- **A2（答题的考生）**：轮到他答题，但他**看不到图**。

常规多智能体系统（**Text-MAS**）里，A1 写一张**文字纸条**（"图里有一只红色的圆……"）传给 A2——写纸条慢（逐字生成），且写下来的永远比脑子里想的少。

**LatentMAS** 的主意：别写纸条，**把 A1 的"思维底稿"整叠传过去**。底稿 = **KV cache**——模型读题、看图时在每一层留下的中间计算结果（每个 token 在每层存一份 Key 和 Value 张量）。A2 拿到底稿后，他生成的每个字都能靠注意力"回头翻看"这叠底稿，相当于直接接上 A1 的思路。

LatentMAS 还有个附加动作——**默想页**（latent steps，页数记作 **m**）：A1 交底稿前可以"闭卷默想" m 步——不写字，把自己最后一层的思维向量（hidden state）直接喂回给自己当下一个输入，多想一轮底稿就厚一页。这些页是**连续向量伪 token**，不对应词表里任何真实的字。

**翻译器（W_a）**：LatentMAS 论文里的一个矩阵，负责把默想页的思维向量"翻译"回输入嵌入的格式（从词表矩阵闭式解出，无训练）。代码默认**不开**它（用单位阵=什么都不做，只把模长归一到嵌入表平均值）；开了才是真翻译。Phase 1 发现开真翻译器在 LLaVA-1.5 上会让下游 agent 直接闭嘴（EOS 毒性），机制见 §4 B2。

### 0.2 机制拆分：M1 与 M2

LatentMAS 可拆成两个独立机制，**Phase 1 证明它们命运完全不同**：

| | 机制 | 比喻 | Phase 1 判决 |
|---|---|---|---|
| **M1** | agent **内部**的 m 步潜在思维（默想页） | 闭卷默想 | 零载荷（撕掉不掉分）——Phase 2 轴 A 要验它是否跨任务成立 |
| **M2** | agent **之间**的逐层 KV 传递（整叠底稿交接） | 传底稿 | 载荷巨大（+41.7pp）——Phase 2 要在正式考场重立 |

### 0.3 全部臂的定义（盲考实验的"对照组军团"）

盲考实验里，同一批题在多个"臂"（arm，实验条件）下各答一遍。每个臂只改一件事：

| 臂 | 全称比喻 | 谁看图 | A2 收到什么 | 存在的目的 |
|---|---|---|---|---|
| **U** | 开卷（Upper bound，上界） | **A2 自己** | 图 + 题 | 天花板：亲眼看图能考多少分 |
| **L** | 盲猜（Lower bound，下界） | 没人 | 只有题 | 地板：什么都不传能蒙多少分。**通道的贡献 = X − L** |
| **T** | 传纸条（Text-MAS） | A1 | A1 写的 ≤128 token **文字描述** | 文字通道的对照：底稿比纸条好多少 = X − T |
| **X** | 传底稿（Latent-MAS 主臂） | A1 | A1 的**完整 KV**（读图底稿 + m 页默想），**不见图不见字** | 主角 |
| **Xprm** | 撕默想页（prompt-only KV） | A1 | 只留 A1 读图/读题部分的 KV，**把 m 页默想撕掉** | 载荷定位：X ≈ Xprm ⇒ 默想页没装货（M1 零载荷的判据） |
| **Xshuf** | 换别人底稿（shuffle） | A1（但看的是**别的题的图**） | **上一个样本**的真底稿 | 安慰剂对照：如果 A2 根本没读底稿、只是"手里有叠纸就安心"，换成错的底稿分数不该掉 |
| **XWa** | 开翻译器 | A1 | 同 X，但默想页经过**真 W_a** 翻译 | 隔离翻译器的贡献/毒性 |

Phase 1 还跑过两个臂，Phase 2 不再需要：**Xrand**（高斯随机假底稿——比 Xshuf 更狠的安慰剂，结果是乱码）、**Xlat**（只留默想页、撕掉读图部分——结果 A2 说不出话，证明干货全在读图 KV 里）。

**夹逼逻辑**：X 的成绩必然落在 L（啥都没有）与 U（亲眼看图）之间；X 比 L 高出多少，就是 KV 通道实际传过去的信息量；X 与 Xshuf 之差剔除"占位安慰剂"效应；X 与 Xprm 之差单独量默想页的贡献。

### 0.4 统计工具两分钟版（本文用到的）

- **配对设计**：所有臂答**同一批题**，逐题配对比较（不是各测一批再比平均分）——灵敏得多；
- **McNemar 精确检验**：配对二值结果的显著性检验。只看 **discordant pairs**（两臂一对一错的题——两臂全对或全错的题不提供区分信息）。报告必须给 discordant 对数：太少（<20）时任何结论都不可信；
- **检出力**：样本量决定能"看见"多大的差异，规律是**可检出差异 ∝ 1/√n**（样本翻 4 倍，可见差异减半）。

## §1 为什么 Phase 1 的结论要"重立"——诊断证据 vs 正式主张

打个比方：Phase 1 像**预审**——证据（+41.7pp、安慰剂排除、默想页无用）足以让案子成立、值得开庭；但预审用的那批证据全部采自**同一个考场**（POPE：问"图里有没有 X"的是/否题库），而这个考场后来被裁定"题太简单、不具代表性"（二选一、感知型、答案直接躺在图里不需要思考）。

于是规则很朴素：**正式庭审的证据必须在被认可的考场重新采集**。这就是计划里"降级为诊断证据、由 GQA+MMStar 重立"的意思——不是说 Phase 1 白做了（它筛掉了死路、校准了仪器、锁定了机制），而是说**论文里的正式数字不能引用它**。

> **桥句 A**：Phase 1 告诉我们"值得测什么、怎么测不会骗自己"；Phase 2 才产出"能写进论文主表的数字"。

**哪些结论不用重立**（与考场无关的）：卡 1 的几何测量、卡 2 的 KV 等价性与页码坍缩、三组探针（质心塌缩/填充行/复印机质检）——这些测的是模型本身，不是任务表现。（但注意：**几何类结论是逐模型的经验事实，换 backbone 要重测**——这是另一维度的"重立"，见分支 phase12-analysis-qa 的 G1-G4 补测。）

## §2 新考场为什么选 GQA + MMStar

回忆盲考设计的命门：**L 臂（盲猜）必须趴在随机线上**，否则"通道贡献 = X − L"的测量空间被压缩。两个考场各占一个理由：

| 考场 | 题型 | 为什么选它 |
|---|---|---|
| **GQA**（取 800 题） | 组合推理、开放短答（"桌子左边的杯子是什么颜色"） | **需要思考的题**——"默想页无用"结论的真正考场。要过滤掉常识可猜题（如"天空是什么颜色"） |
| **MMStar**（1500 题里分层抽 800） | 四选一选择题 | **设计上强制看图**：官方构造时就剔除了"不看图能答对"和"训练数据泄漏"的题——等于**官方替我们保证了 L 臂趴在 25%**。且最强竞品 L²-VMAS 用它，数字可并表 |

两个考场恰好互补：开放题 vs 选择题（两种判分）、推理 vs 六能力混合（两种能力谱）。**MMStar 的"分层抽 800"** = 它 1500 题均匀覆盖 6 种能力（各 250 题），每种抽约 133 题保持配比——考卷按题型等比例抽印。

### 800 题够吗？——功效账

以"620 题检出 5pp"为锚（discordant 率 20% 口径），按 ∝1/√n 换算：

```
单库 800 题   → 检出 ~4.4pp     粗对比(X−L, 预期>15pp)绰绰有余
两库合并 1600 → 检出 ~3.1pp     细对比(X−T、X−Xprm, 可能 2-3pp)靠合并兜底
```

若出现 2-4pp 边缘信号：**只对涉事臂追加几百题**（自适应扩样），不整库重跑。纪律：扩样只加数据、**判决标准不动**——先看结果再改标准就是作弊。

## §3 轴 A：换考场重考（三个实验）

### A1 — 盲考主验证（双考场、全臂）★Phase 2 的核心★

**做什么**：把 §0.3 的整套臂（U/L/T/X/Xprm/Xshuf/XWa）在 GQA 和 MMStar 上原样重跑。

**判决怎么读**（三层，每层独立）：

| 对比 | 阈值 | 读法 |
|---|---|---|
| X − L > 5pp（双考场都要过） | 生死线 | 底稿在新考场还能传动视觉信息 → **H4 正式成立** |
| X − Xshuf > 4pp | 安慰剂线 | 收益来自底稿**内容**而非"手里有叠纸" → **H5 正式成立** |
| X − Xprm 是否 > 2pp | **本轴的主问题** | 见下 |

**X − Xprm 这一条是整个轴 A 的灵魂**。Phase 1 在 POPE 上测得 X≈Xprm（撕掉默想页分数不变）——但 POPE 的答案直接躺在图像 KV 里，**根本不需要思考**，默想页没用武之地或许不奇怪。GQA 的组合推理题需要多步思考——**如果默想页有价值，这里是它最该显灵的地方**：

```
GQA 上 X − Xprm > 2pp 且显著  →  默想页在推理任务有载荷
                                  "砍掉 M1"必须收窄成"感知型任务上可砍"
GQA 上仍然 ≈ 0               →  "默想页无用"升级为跨任务结论,砍 M1 的主张写硬
```

**两种结果都能写**——这是好实验的标志。

XWa 臂捎带跑：复核"开翻译器就闭嘴"（EOS 毒性，Phase 1 在 LLaVA-1.5 上 1000/1000 全空输出）是否跨任务/跨模型成立。

### A2 — 默想时间扫描（m 扫描）

把默想页数 m 从 0 扫到 40（{0,5,10,20,40}），只跑 X 臂，看**分数-页数曲线**：

```
若曲线有正斜率 → "默想的价值随任务推理深度增长"——比"默想无用"有趣得多的一篇的种子
若全平        → 与 A1 互证, M1 彻底可砍
```

m=0 的数字不用单独跑：它与 Xprm 内容等价（都没有默想页）。感知型对照点直接引用 Phase 1 POPE 的 X≈Xprm。

### A3 — 复印机质检正式版

背景：把 W_a 想成复印机，问"翻译后的默想页还带多少**样本特有**的信息"。量法是**区分度预算 = 1 − 平均两两 cos**：拿 N 个不同题目的默想页向量互相比方向，如果翻译把一切压成同一个向量，两两 cos → 1、预算 → 0（复印成同一张纸=信息销毁）；预算越大说明样本间差异保留越多。Phase 1 的 8 样本小探针测得 W_a 保留约 73% 预算——"信息被降级，没被销毁"。

A3 升格：**200 样本 × 多模型 × 整条 rollout 轨迹**（默想不止一步，逐步量预算怎么演化），画"区分度-步数"曲线。

关键读数是**关联**：几何上残存的信息量（A3）与行为上的载荷（A1 的 X−Xprm）**是否同涨落**——如果某模型上区分度保留多、行为上默想页也开始有用，"几何→行为"的因果链才立得起来。

## §4 轴 B：修考场（两个实验）

### B1 — M-RoPE 页码接管模块

**背景两分钟版**（深挖见 [phase1-cards-explained.md](phase1-cards-explained.md) §5 与 [Q&A/02](../Q&A/02-why-append-works-in-text-but-breaks-in-multimodal.md)）：每页底稿的"页码"（RoPE 位置）是写进 K 向量旋转角里的。1D 页码（LLaVA 系）下"第几个 token=第几号位置"，续算时按 cache 长度接着数永远正确；**Qwen 系的 M-RoPE 页码是三维的 (时刻,行,列)，且图像按"面"占位**——177 个 token 的最大页码可能只到 44，"token 数=位置数"恒等式被打破，而正确续号需要的账本（已用最大坐标、图的网格形状）**不随 past 传递**。Phase 1 实测：不管页码 → 崩（Δlogit=33）；按 token 数续 → 也错（Δ=19.3）；喂正确三维页码 → 完全修复（top-1 100%）。

**B1 做的事**：把"正确三维页码"从一次性诊断变成**生产模块**（MRopeTracker）——跨 agent 续算时自己记账："当前最大坐标"逐段更新，文字按 max+1 三轴同值续、新图按网格铺、默想页逐个 max+1。开发靶 **Qwen3-VL-8B**（其 M-RoPE 是 interleaved 变体，与 Qwen2.5-VL 实现不同，等价性测试要重跑）。

**验收两级**：①数值等价（tracker 位置与金标准逐位一致、top-1 100%——"分段续算"与"一次算完"逐字相同）；②盲考 X−L > 5pp。通过 → "KV 通道传视觉信息"从单模型升级为**跨位置编码方案**的结论。**这是解锁 Qwen 全家的钥匙，也是四篇已有论文都没做的工程点。**

### B2 — "EOS 毒性 = 词表工程巧合"假说验证（搭便车，+2 小时）

**悬案两分钟版**：Phase 1 发现开真 W_a 后 LLaVA-1.5 的下游 agent 全部"闭嘴"（1000/1000 第一个生成 token 就是结束符 EOS），而同样的 W_a 在纯文本 Qwen3-8B 上无害。探针追出的机制链：W_a 是对全词表的最小二乘回归 → 对陌生输入回归塌向嵌入**质心**（全部真 token 向量的平均）→ 质心是嵌入空间的"荒地"，住那里的永远是**没训练过的行**。分岔在于荒地上盖了什么：**LLaVA-1.5 的填充行**（嵌入矩阵为 GPU 对齐补的空行）被 HF 用 **mean-init**（=均值）初始化，恰好整齐地盖在质心上、语义等价于"空白页"——翻译后的默想页强烈匹配这批空白行（cos 0.70），回答槽被"空白腔"塞满 → EOS；**Qwen 的填充行是随机初始化**，不住质心，翻译产物只是弱匹配的乱码 → 被无视。

**B2 的预注册预测**（先查 Qwen3-VL 填充行是不是随机 init，是则预测）：**Qwen3-VL 的 XWa 臂不闭嘴、但也不显著加分。**

> **什么叫预注册**：动手实验**之前**把预测白纸黑字写下来。中了 → 假说闭环，"毒性一半是 LLaVA-1.5 词表工程巧合"写进论文；不中 → 假说推翻、重新归因。先写预测再看结果，堵死"马后炮解释"的路——这正是 Phase 1 里被追问逼出来的纪律。

## §5 轴 C：大考出分（两个实验，A/B 通过后才开）

### C1 — 完整 4-agent MAS 主表

前面所有实验都是**两个 agent 的最小机制测试**；C1 才是论文的门面：**完整四角色 MAS**（Planner 规划 → Critic 批评 → Refiner 精炼 → Judger 定稿，LatentMAS 原版角色链）× 双 backbone × 正式考场的成绩单。设计原则延续单变量：**两种 MAS 里都只有 Planner 看图**，通信介质（文字接力 vs KV 接力）是唯一变量。

方法臂的设计意图：

| 臂 | 定义 | 回答什么 |
|---|---|---|
| Single | 一个 agent 直接看图作答（≈盲考的 U） | 多智能体到底比单打独斗强吗（L²-VMAS 证明文本 MAS 常常更弱） |
| Text-MAS | 四角色靠**文字**接力（每人读前人的文字输出） | 传纸条 vs 传底稿 |
| Latent-MAS (m=0) | 四角色靠 **KV** 接力、**不带默想页**——纯 KV 版 | 若轴 A 证实 M1 可砍，这就是主推配置 |
| Latent-MAS (m=10) | 同上但每角色默想 10 页 | 原版对照 |

防坑设计：**避开 MMBench**（L²-VMAS 在它身上有 3 处负增益前科，绕开争议考场）；greedy 解码（确定性，免多 seed）；每格 800 题 + McNemar + discordant 报告（与 A1 同一套统计纪律）。

### C2 — 成本三口径（与 C1 同跑）

效率主张必须同时报三个数：**生成 token 数 / 端到端墙钟 / 峰值显存**，且**同时给 vs Text-MAS 和 vs Single 两列**。

为什么死磕"vs Single"：L²-VMAS 的教训——它报"token 省 21-45%"只对比文本 MAS，相对单模型其实**贵 5 倍**。两列都摆出来，审稿人挑不出这个刺。另扫 agent 数 N∈{1,2,4,6,8} 看 KV 链长度增长（底稿越传越厚的账）。

## §7 追问区（预判的坑）

**Q1：为什么不直接跑 C1 主表？**
C1 是四角色全家桶，任何一个环节坏了都无法归因（Phase 1 "一次只让一个东西可疑"的纪律仍在）。A1 先用两 agent 最小结构把通道验干净，C1 的数字才有解释权。

**Q2：XWa 不是已经证明有毒了吗，为什么还跑？**
两个原因：①毒性测自 POPE+LLaVA-1.5，跨任务（A1）、跨模型（B2）都需复核；②B2 的预注册预测恰好需要它——它从"已知有毒的臂"变成了"验证毒性成因的探针"。

**Q3：GQA 为什么要过滤"常识可猜题"？**
L 臂的意义是"不看图能拿多少分"。若考卷混着"消防栓通常什么颜色"这类题，L 会虚高、压缩 X−L 的测量空间。过滤方式：先让纯文本模型盲答一遍，答对率过高的题剔除。

**Q4：MMStar 的 25% 随机线怎么来的？**
四选一选择题，闭眼蒙的期望正确率 = 1/4。比 POPE 的"是/否"（50%+先验偏置实测 47-57%）干净得多。

**Q5：自适应扩样算不算作弊？**
只加样本、不动判决标准，且扩样决定只依赖"效应落在边缘区间"这一事实——可接受。作弊的是：看完结果把阈值从 5pp 改成 3pp，或只在"快显著"时扩样直到显著（p-hacking）。规则写死在计划里。

**Q6：为什么 A1 用 LLaVA-OV 而不是等 B1 修好 Qwen3-VL？**
LLaVA-OV 是现代模型里的 1D 页码系（Qwen2-LM 骨干），**不需要接管模块就能跑**——A1 立刻开工，不被 B1 的两天工期堵住。Qwen3-VL 的复刻在 B1 通过后补（即 B1 验收②）。

**Q7：Xshuf 为什么用"上一个样本的底稿"而不是随机数？**
Xshuf 的底稿是**真底稿**（统计性质、格式全对），只是内容对不上这道题——单独隔离"内容"变量。随机数（Phase 1 的 Xrand 臂）连统计性质都不对，是更粗的对照。若出现 Xrand < Xshuf < X 阶梯，"格式效应"与"内容效应"各占多少一目了然。

|---|---|
| 底稿 / KV cache | 模型读每个 token 时在每层存下的中间结果（Key/Value 张量）；后续 token 靠注意力回看它 |

| 翻译器 / W_a | 把思维向量翻译回输入嵌入格式的闭式矩阵；代码默认关（单位阵+模长归一） |

| U / L / T / X | 开卷上界 / 盲猜下界 / 传纸条(文字) / 传底稿(KV) |
| Xprm / Xshuf / XWa | 撕默想页(载荷定位) / 换别人底稿(安慰剂) / 开翻译器(毒性探针) |
