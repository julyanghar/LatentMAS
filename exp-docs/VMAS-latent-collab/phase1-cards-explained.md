## TL;DR

一句话版：**四张卡合起来回答一个问题——"看过图的 agent，能不能靠传 KV cache（不写一个字），把图里的信息交给没看图的 agent？"**

- **卡1**：检查"翻译器"（$W_a$）是不是空转的 → 决定一个理论问题是真是伪

- **卡3**：**生死线** —— 盲考实验，直接测"图的信息到底传没传过去"
- **卡4**：安慰剂对照 —— 排除"随便传点什么都能涨分"的假象

## §1 起点：LatentMAS 在做什么（一个比喻贯穿全文）

想象一场考试，有两个学生：

- **A1（看图的同学）**：拿到了考卷上的图，仔细看了
- **A2（答题的考生）**：轮到他答题，但他**看不到图**

常规多智能体系统（Text-MAS）里，A1 会写一张**文字纸条**（"图里有一只红色的圆、一个蓝色的方块……"）传给 A2。写纸条很慢（要一个字一个字生成），而且写下来的永远比脑子里想的少。

LatentMAS 的主意是：**别写纸条了，直接把 A1 的"思维底稿"整叠传过去。** 这叠底稿就是 **KV cache**——模型读题、思考时在每一层留下的中间计算结果。A2 拿到底稿后，他自己的每个字都能"回头翻看"这叠底稿（注意力机制），相当于直接接上了 A1 的思路。

> **桥句 1（后文反复用）**：KV cache 是"思维底稿原件"，不是"总结陈词"——传底稿省掉了"写出来"和"再读进去"两道工序，但底稿是否**可读**、里面有没有**干货**，都需要验证。

LatentMAS 还有个附加动作：A1 交底稿前可以先"闭卷默想" $m$ 步（**latent steps**）——不写字，把自己的最后一层思维向量直接喂回给自己，多想几轮，底稿变厚 $m$ 页。

这套东西在**纯文字**考试里已被验证有效（LatentMAS 论文，ICML'26）。我们要做的是把它搬到**看图**的考试里——这是没人做过的（四篇相近工作全都需要训练，我们走免训练路线）。

## §2 为什么不能直接跑，要先体检

把系统直接搬过去跑分，如果分数不好——**你不知道是哪里坏了**。可能性至少有四个：

| 疑点 | 大白话 | 出处 |
|---|---|---|
| ① 翻译器可能空转 | LatentMAS 有个矩阵 $W_a$ 负责把"思维向量"翻译回"输入格式"。但我们读源码发现：**默认配置下它就是个单位阵（什么都不做）** | [code-to-paper-mapping.md](../code-to-paper-mapping.md) §4.1 |
| ② 页码可能错乱 | Qwen-VL 系模型的位置编码是三维的（M-RoPE）。我们实测发现：LatentMAS 的调用方式会让**每一页默想底稿的页码都变成第 0 页**，且不报错 | [research-digest.md](research-digest.md) §4.1 |
| ③ 底稿里可能没有图 | 图的信息经过几十层计算后，留在 KV 里的还剩多少？没人量过 | 本项目要回答的问题 |
| ④ 涨分可能是假象 | 有已发表工作证明：latent 通道的"收益"可能来自消息**存在本身**（占了位置、改变了解码状态），而不是消息**内容** | arXiv 2607.26773 实测 |

> **桥句 2**：**一次只让一个东西可疑。** 四张卡就是把四个疑点拆开、逐个单独检查——这是全部设计的核心逻辑。

排序原则：**便宜的先跑，上游的先跑。** 卡1 一小时（几乎不用 GPU），卡2 三小时，卡3 要搭 pipeline 跑一天，卡4 复用卡3 的代码。而且卡2 不过，卡3 的失败就无法归因——所以顺序是死的。

## §3 主实验台为什么选 LLaVA-1.5-7B，而不是更新的 Qwen2.5-VL

这本身就是"一次只让一个东西可疑"的应用：

- **LLaVA-1.5** 的位置编码是普通一维 RoPE，图就是 576 个普通位置——**疑点②在它身上不存在**
- **Qwen2.5-VL** 的 M-RoPE 是三维的——疑点②恰恰在它身上

所以：主实验（卡3/卡4）在 LLaVA 上跑，先回答"机制本身行不行"；Qwen 只在卡2 里出场，专门测"页码错乱"这个坑本身。如果一上来就用 Qwen，卡3 失败时你分不清是③还是②。

## §4 卡1 — 翻译器是不是空转的？（1 小时）

### 为什么要有这张卡

$W_a$ 是 LatentMAS 唯一的"理论部件"（论文为它证了个定理）。而它的闭式解**只对文字词表有定义**——图的向量根本不经过词表。这曾被我们认为是"理论断点"，是最想攻击的点。

但读源码发现了反转：**LatentMAS 代码默认不开 $W_a$**（不传 `--latent_space_realign` 时它是单位阵，见 [models.py:179-183](../../models.py#L179-L183)）。如果它在我们要用的模型上也约等于单位阵，那"断点"就是个**伪问题**——一个空转的零件谈不上坏。

> 这张卡花一小时，决定一个写作方向：**"$W_a$ 不适用于视觉"这句话能不能当论文卖点。** 不跑这张卡就写 pipeline，可能对着一个不存在的问题设计一堆方案。

### 怎么跑（真实数字）

加载 LLaVA-1.5-7B，用它的词表矩阵解出 $W_a$，量三个数：

1. **$W_a$ 离单位阵多远**：`rel‖Wa−I‖` <0.01 → 空转；>0.1 → 真有作用
2. **图向量落在文字空间的哪里**：把图经过 projector 后的 576 个向量，投到"文字嵌入表的前 256 个主方向"上，看能量占比。>0.8 → 模型训练时已经把图对齐到文字空间了（好消息：照搬无害）；<0.19 → 图和文字住在两个世界（断点真实）
3. **模长差多少**：我们在纯文本模型上实测过隐状态比嵌入大 **132 倍**（Qwen3-0.6B：122.17 vs 0.925）——图模型上这个比值也要量，它决定"模长归一"这步有多重要

### 判决表

| 观测 | 结论 | 对后面的影响 |
|---|---|---|
| $W_a\approx I$ | 断点是伪问题 | 不谈 $W_a$，火力全部转向 KV 通道 |
| $W_a$ 非平凡 + 图已对齐到文字空间 | 照搬无害 | 免训练可行性 +1，但"$W_a$ 改进"这个方向失去动机 |
| $W_a$ 非平凡 + 图文两个世界 | **断点真实** | "多模态版对齐算子"成为有价值的改进方向 |

### 卡 1 实际结果证明了什么（通俗总结，实验已完成）

三个测量各一锤：
1. **翻译器不是空转的**（rel‖Wa−I‖≈1.15，两模型均 untied）——"假问题"出口封死，W_a 值得谈；
2. **图和文字住在两个世界**（视觉能量占比=随机基线）——projector 根本没把图翻译成文字的样子，模型却照样读得懂 → **LatentMAS 拿"文字嵌入表"当参照系的一切对齐操作，尺子比桌子短**；
3. **默认配置的默想是外星笔迹**（cos 0.06 vs 开 W_a 的 0.71）——据此曾推断"W_a 可能是必需品"，**后被卡 3 行为实验推翻**（W_a 把向量拉到文字区正中心=pad 语义，反而触发 EOS）。教训：**几何测量只能说"东西在哪"，不能说"模型怎么对待它"，判决必须靠行为实验**。

合并判决：断点真实——W_a 真实存在但对着错误参照系工作、默认配置产出模型读不懂的东西、视觉信息另有通路（卡 3 证实：干货全在图像 KV）。对改进的约束：**多模态对齐算子的目标不能选文字嵌入表**。

### 深入一层（追问回填）：rel‖Wa−I‖ 是什么

完整写法 `‖Wa−I‖_F / ‖I‖_F`：把 Wa 与单位阵 I（"什么都不做"的变换）逐元素相减，差异矩阵的 Frobenius 范数（所有元素平方和开根——矩阵拉直成长向量后的模长）÷ 单位阵自己的范数（√4096=64），得到一个不随维度变的**相对值**。

手算例（2×2）：

```
Wa = [1.1  0.2]    Wa−I = [0.1  0.2]    ‖Wa−I‖_F = √0.06 ≈ 0.245
     [0    0.9]           [0   −0.1]    ‖I‖_F = √2 ≈ 1.414   →  rel ≈ 0.17
```

**为什么拿 I 当参照物**：I 正是两种"W_a 失效"情形的化身——代码默认就用 I（不传 flag）；tied 模型上真 W_a 数学退化成 ≈I。所以这个数问的是"真解出来的 W_a 和空转有没有区别"：rel<0.01 → 空转、断点是伪问题；rel>0.1 → 非平凡。实测 1.147/1.187——**差异矩阵比单位阵还大**，两个模型（均 untied）的 W_a 都是彻底非平凡的变换，"伪问题"出口封死，它帮忙还是帮倒忙交给卡 3 行为判决（答案：质心塌缩→EOS，帮倒忙）。

### 深入一层（追问回填）：这里的 projector 是谁（不是 W_a）

测量二里"图经过 projector"指 **VLM 自带的视觉投影器**（LLaVA-1.5：CLIP 视觉塔后的两层 MLP，训练出来的，把 576×1024 的 patch 特征映成 576×4096、替换 `<image>` 拼进输入序列；代码 `m.get_image_features(...)`）。**不是 W_a**——W_a 是 LatentMAS 从词表闭式解的对齐矩阵，只在测量三作用于末层 h，从不碰视觉 token。

顺带点破：教程常说 projector"把视觉投影到文本空间"，测量二证明其准确含义是**投到 LLM 能吃的 4096 维输入空间（维度对齐）**，而非投进文字嵌入的分布（能量占比=随机基线，几何上完全在薄饼外）。**维度兼容 ≠ 分布对齐**——VLM 训练教会 LLM 读懂"薄饼外的方言"，而不是把方言翻成官话。

**"W_a 对着薄饼对齐在 VLM 上注定跑偏"的完整推理**（追问回填，三层）：W_a 的构造原料只有两张文字词表矩阵——一台只学过官话词典的翻译机。①**目标选错**【卡1实锤】：VLM 合法输入世界 ⊋ 薄饼（视觉 token 46×模长、正交、模型照读），"必须长得像文字"这个约束多余——如同要求所有进楼者穿西装，而半数住户穿宇航服、门卫从不拦；②~~丢的恰是载荷~~【⚠️ 已降级为存疑假说】：原表述"h 里有用的正是视觉味方向、被 W_a 压掉"**预设了 h 携带可传递的视觉载荷，该前提本会话未验证**，且与卡 3 数据有张力——X≈Xprm、Xlat=空输出说明**连默认配置的 latent 页都无载荷**，载荷从没上过这趟车，谈不上"被 W_a 扔掉"。latent 页为何无载荷是开放问题，三个嫌疑人：**口水页**（默想没产生超出读图笔记的增量，可用探针测默想页残余图像信息）/ **纸太小**（单向量带宽装不下图像信息，可加大 m 或换多向量）/ **不识字**（信息在页上但 A2 没学过读伪 token 页，可换提示引导），现有数据分不出是谁，待 Phase 2。**撤诉逻辑**：指控"快递员（W_a）丢了货"之前得先证明发件人装过货——而不经 W_a 的箱子也是空的（X≈Xprm），W_a 坐实的罪只有"把空箱子换成毒箱子"（质心塌缩→EOS）；③**输出塌向平均音**【卡3+探针实锤】：回归对词典没见过的输入退化到目标均值——实测 h@Wa 与质心 μ 的 cos=0.70，质心住着 pad/未训练行 → 空白腔塞满回答槽 → EOS。对照：同一台机器在纯文本模型里正常，因为那里薄饼=输入世界全部、h 是官话内容、回归在分布内——**坏的不是机器，是任务书在 VLM 上从根子上写错**。第②层待坐实（需"h 的视觉信息方向分解"实验，Phase 2 可选）。

### 深入一层（追问回填）："投到文字嵌入表的前 256 个主方向"是什么

**主方向（PCA 主成分）**：把嵌入表看成 4096 维空间里 3.2 万个点组成的**点云**。点云不是均匀散布的，它挤在一个远比 4096 维扁的"薄饼"里。主方向 = 点云伸展最开的方向：第 1 个 = 方差最大的方向，第 2 个 = 与第 1 垂直中方差最大的，…取前 256 个 = **文字薄饼的骨架**。（脚本对应：先 `mu = Win.mean(0)` 减去点云中心，再 `pca_lowrank(Win-mu, q=256)`。）

**投影与能量占比**：任何向量 v 可唯一拆成「落在这 256 个方向里的分量 + 落在其余 3840 个方向里的分量」。能量 = 各分量平方和（长度平方）：

```
             ‖v 在 256 维子空间内的分量‖²
能量占比  =  ─────────────────────────────    = v 的"体重"有几成压在文字薄饼里
                       ‖v‖²
```

**为什么取前 256 而不是全部**：全部 4096 个方向张成整个空间，任何向量 100% 在里面，没有区分度；只有取"文字最集中的少数方向"才能问"你是否也集中在同一片"。

**"薄饼" ≠ 张成的空间（追问回填）**：32000 个 4096 维向量的 span 秩满 = **整个空间**，任何向量都在里面，毫无区分度。薄饼指的是**分布**——点云实际堆放的区域（典型模长~1、方差集中的主方向、高密度带）。"正交于薄饼"= 能量避开文字点云方差集中的方向，不是"在 span 外"（数学上不可能）。

**"能被 LM head 解码 ⇒ h 在文本空间"不成立（追问回填）**：①softmax 对任何向量都输出合法分布，"能解码"是空约束；②解码走内积 `logit = ‖h‖·‖w‖·cos`，h 模长 122 会把微小 cos 放大成尖锐 logit 差——实测 h 方向与全词表 cos 仅 0.06 仍解码良好。**"能被词表读出"≠"住在词表附近"**：LM head 只是一支读取 h 某个线性投影的探针，4096 维里其余自由度它视而不见（残差流=多路信号叠加的总线）。细节：量 cos 用 W_in、解码用 W_out，untied 下是两张表。

**随机基线 256/4096=6.25% 是怎么来的**（两行对称性论证）：**方向在球面上均匀**的随机向量，没有任何坐标轴是特殊的 → 每个坐标分量分到的能量比例期望全相等，4096 份加起来=1，每份 1/4096；任意固定 256 维子空间收下 256 份 → 256/4096=6.25%。（注意"每分量随机取值"必须是 **iid 高斯**才等价于方向均匀——若是 iid 均匀[0,1]，分量全正、方向挤向对角线，基线失效。基线是纸上算的假想刻度，实验里量的是真实视觉向量、拿去和它比。）

三个易误解点（追问回填，均经蒙特卡洛核过）：
- **高斯是均值 0**（如 N(0,1)），不是"均值 1/4096"——1/4096 是推导的**输出**（每轴期望能量份额），不是分布参数；方差随便取（占比是比值、尺度消掉，实测 N(0,37²) 均值 0.0624 不变）。
- **子空间不用选**：对方向均匀的向量，任何固定 256 维子空间期望占比都是 k/d（实测：坐标轴子空间 0.0626、随机旋转子空间 0.0626，一样）。真实测量里子空间= PCA 的 V256，基线的含义是"若视觉方向与文字无关，这个子空间平均也只接得住 6.25%"。
- **基线没有真的采样**——6.25% 是解析解；蒙特卡洛只是验证（d=4096、1 万样本，均值 0.0626、标准差 0.005）。单次有波动，池了 1700+ 真视觉 token 后实测紧贴基线，本身就是强"独立"证据。
- **MC 的具体做法**（追问回填）：①造向量 `v = randn(4096)`；②造"任意朝向"的子空间用 QR——`Q,_ = qr(randn(4096,256))`：`randn` 给 256 根随机高斯方向（张成 256 维子空间，但互不垂直、长度不一，直接投影会重复计能量）；`qr` 做 Gram-Schmidt 逐根扶正（每根减去在前面各根上的影子再归一化），得到**同一个子空间**的一套两两垂直、单位长的坐标轴（歪尺子换方格尺，桌面不变）。注意**除第一根外每根的方向都被转动了**（减影子必转向，手算例中 q2 与 a2 差 30°）——不变的是张成的子空间（含每个前缀 span），不是各向量自己的方向；顺序不同输出也不同。对投影能量而言只需子空间不变，故无碍；`Q,_` 是拆包丢弃记账矩阵 R。Q 的 256 列即一组正交单位方向（PCA 的 V256 是同样格式，只是方向从文字点云学出而非随机）；③投影坐标 `c = Q.T @ v`，占比 `= (c**2).sum()/(v**2).sum()`——与卡 1 脚本 `((vis-mu)@V256)**2` 同一含义。坐标轴子空间与 QR 随机子空间均值同为 0.0626 → "子空间怎么选不影响期望"实测坐实。双重校验：均值偏差 0.0001 ≈ 2 个标准误；实测标准差 0.0053 与精确分布 Beta(128,1920) 的理论值 0.0053 严丝合缝。
- **三个易混的数**：0.0625 = 理论预言（256/4096，纸上推的）；0.0626 = 同一个量的 MC 实验读数（一万次采样均值，验证尺子可信）；0.060 = 真视觉 token 的实测占比（拿验证过的尺子量真实对象）。逻辑：0.0626≈0.0625 证明尺子没错 → 0.060≈0.0625 判视觉与文字独立。三维验证（地面子空间，基线 2/3）：v=(1,1,1) 占比恰 2/3；v=(0,0,1) 得 0（避开）；v=(1,1,0) 得 1（偏好）；球面平均=2/3。我们池了 3 图×576 token 求平均，估计值紧收在期望附近。

三档读法：**≫基线=偏好文字方向；≈基线=与文字结构统计独立（闭眼选的方向）；≪基线=主动避开（反对齐，比独立更奇怪）**。"等于基线"的准确含义是**独立**、不是"相反"。基线值对任何固定 256 维子空间都成立（子空间特不特殊不影响），前提只是被测向量的生成与该子空间无关——所以"实测=基线"是在说视觉向量与文字结构无关。

**三维比喻**：文字点云 = 一座城市，几乎全在地面伸展（主方向=东西、南北，高度方向很薄）。视觉向量 = 一架飞机——看它的位置向量有多少能量落在地面平面内，就知道它是不是"城市居民"。

**实测读法**：LLaVA 0.060 vs 基线 0.062、Qwen 0.071 vs 0.071——**精确等于随机基线**，视觉 token 对文字薄饼零偏好 → 图文两个世界，断点真实。但注意与卡 3 合读：住在薄饼外的视觉 KV 照样被 LLM 读得很好（X 臂 89%）——"薄饼外"≠"读不懂"，只说明**模型可接受的输入流形远大于文字嵌入表**；真正读不懂的反而是塌缩到薄饼正中心（质心≈pad 语义）的 Wa-latent。

**为什么要做这个测量**：它检验的是 LatentMAS 全部对齐操作的**参照系**。$W_a$ 的对齐目标、模长归一的 target，全都以"文字嵌入表 ≈ 模型输入的样子"为前提——纯文本模型里这是废话，VLM 里输入还包括 projector 的视觉向量，前提不再自动成立。三种测量结果对应三条路：占比>0.8 → projector 已对齐、$W_a$ 照搬无害、**不用设计新东西**；占比≈随机 → 参照系塌了、"多模态版对齐算子"是真问题（实测落在这格）；$W_a\approx I$ → 参照系问题根本不触发。Meta 理由是**测量前置于设计**：花 1 小时确认问题存在，再决定要不要花数周解决它——判决表里"改进方向失去动机"那格就是给"问题不存在"留的出口。

## §5 卡2 — 底稿拼接时页码会不会乱？（3 小时）

### 为什么要有这张卡

LatentMAS 的根基是一个数值等式：

> **桥句 3**：「A1 先算、把底稿传给 A2 续算」必须等于「A1+A2 的内容合在一起从头算一遍」。**等式成立，传底稿才叫无损通信；不成立，传的就是一叠乱码。**

纯文本模型上这个等式天然成立（我们实测过：fp32 下两条路径差 8.45e-05，就是浮点噪声）。但 VLM 上有个具体的雷：**位置编码**。

每一页底稿都带"页码"（RoPE 位置）。Qwen-VL 系的页码是三维的（时间/高/宽），而 LatentMAS 的代码调用模型时**不传页码，让模型自己猜**。猜号规则=「新 token 位置 = past 长度起接着数」；纯文本下恒等式「token 序号≡位置号」保证这条规则**没有出错的可能**（并非位置不重要，而是默认猜测恒中）；Qwen-VL 我们已实测猜错——**每一页默想底稿的页码都是 0**（hook 抓到每个 latent 步实际收到的 position_ids = [0,0,0]，t/h/w 三轴全塌；期望是接着 prompt 的最大坐标排 45,46,47…）。注意 KV cache **物理上没有覆盖**——m 页仍是 m 条独立记录；被摧毁的是**位置身份**：页码是写进 K 旋转角里的，全 0 意味着 m 页的旋转角完全相同 → ①页与页**不可排序**（时序结构抹平，即"地址上叠在同一个门牌号"）；②集体自称在**序列开头**（与第一个 token 同址），A2 从 45+ 往回看时语境关系整个错位；③全程**不报错**。一团浆糊 = 一叠没有先后、挤在错误门牌号上的纸。（事后看：latent 页本就零载荷，此伤不致命；但**同根因**打坏的 A2 文本续算——从 0 重启、Δlogit=33——是致命的，tracker 接管模块因此而生。）

### 怎么跑

同一段"图 + 文字"内容，走两条路径算，逐位对比输出：

- **P1（金标准）**：内容合在一起，一次算完
- **P2（LatentMAS 机制）**：先算 A 段拿底稿，B 段带着底稿续算

LLaVA 上预期 P1≈P2（一维页码没这个坑）。Qwen2.5-VL 上跑三个变体：(a) 不管页码（现状）；(b) 手动给连续页码；(c) 用金标准的三维页码。看哪个变体能把等式救回来。

### 判决表

| 观测 | 结论 |
|---|---|
| LLaVA 上 P1≈P2 | 机制在一维页码的 VLM 上**原生可用** → 主实验台锁定 LLaVA，卡3 放心跑 |
| Qwen (a) 崩、(c) 救回来 | 页码必须显式接管——这是**四篇已有论文都没写过的技术点**，写清楚本身就是贡献 |
| Qwen 三个变体全崩 | M-RoPE 系结构性不兼容——本身是可发表的负面结论 |

### 深入一层（追问回填）：页码不是写在纸上的，是写进 K 的旋转角里的

> 本小节回答两个追问：①位置编码到底在哪一步加进去、LatentMAS 怎么处理的；②M-RoPE 三轴和 1D 差在哪。读懂它，卡 2 的三个变体为什么各自错/对就一目了然。

**① 位置编码何时加入——不在 embedding 阶段，在每一层注意力算分的那一刻**

```
老式 (GPT-2 / BERT)：输入端注入
  token id → 查嵌入表 → token_emb + pos_emb → 进第 1 层
                          ~~~~~~~~~~~~~~~~
                          位置在这里、只在这里加一次

RoPE (Llama / Vicuna / Qwen 全家)：逐层注入
  token id → 查嵌入表 → 纯语义向量，不含任何位置信息
  每一层内部:
      x → 投影出 Q, K, V
      Q, K 各自旋转一个「与自己位置成正比的角度」  ← 位置在这里注入
      算注意力分数 Q·K   （V 和残差流全程不带位置）
```

RoPE 把向量拆成许多二维小平面、按不同频率旋转；两个 token 的注意力只依赖**旋转角之差 = 相对距离**。两个直接推论：

1. 同一个 token 在位置 3 和位置 300 的**输入嵌入一模一样**。latent 步的伪 embedding 也一样——进门不带位置，位置是每层旋转时按"排在第几个"现场敲上去的。
2. **桥句 3b：KV cache 里存的 K 是已经旋转过的——位置在入 cache 那一刻被"烤进"了 K 里。** 这就是 KV 前置拼接天然携带位置结构的原因（A1 的 K 带着 0~608 的角度躺在 cache 里，A2 的 Q 只要按 609、610…来转，相对距离全对）；也是位置错乱致命的原因（cache 里的角度改不了，新 Q 的角度一错，所有相对距离全错）。

**LatentMAS 怎么"解决"位置：它没有解决，是不需要解决。** 源码里 latent 循环（[models.py:339-346](../../models.py#L339-L346)）位置参数什么都不传；judger 解码（[models.py:232-239](../../models.py#L232-L239)）只传了 `cache_position = arange(past_len,…)`。它搭的是 HuggingFace 的便车：**带 past 前向时，新 token 位置自动 = past 长度接着数**。纯文本 + 1D RoPE 下"token 数 = 位置数"，接着数恰好就是正确答案——所以论文一个字没提位置编码，在它的设定里这不构成问题。

**② 1D vs M-RoPE：一个数字 vs 三个坐标（手算例）**

设迷你序列：2 个文字 + 一张 2×2 小图（4 个 patch）+ 3 个文字。

```
1D RoPE（LLaVA / 纯文本）—— 位置就是排队序号:
  token:   Hi   ,   P00  P01  P10  P11   What  color  ?
  位置:     0   1    2    3    4    5     6     7    8
  （图被拉直成一维: 右边的 patch 差 1, 正下方的差 2 —— 二维邻接被压扁）

M-RoPE（Qwen2/2.5-VL）—— 位置是三元组 (t 时间, h 行, w 列):
  token:   Hi      ,      P00     P01     P10     P11     What   color   ?
  t 轴:     0      1       2       2       2       2       4      5     6
  h 轴:     0      1       2       2       3       3       4      5     6
  w 轴:     0      1       2       3       2       3       4      5     6
```

三条规则：**文字 token 三轴相等**（此时 M-RoPE 数学上退化成 1D，向后兼容）；**图像 token 的 t 整图共用一个值**、h/w 填 patch 的网格行列号（视频每帧 t+1）；**图后面的文字从"已用最大坐标+1"续**——上例图的最大坐标是 3，"What" 从 4 开始，**不是从 token 序号 6 开始**。

实现上，注意力头的旋转维度切三段（Qwen2.5-VL `mrope_section=[16,24,24]`），分别由 t/h/w 驱动——"同行""同列""相邻"这些二维几何直接写进注意力的相对角度。**这就是要三个轴的全部理由**：让模型天生看得懂网格和视频，而不是把图当一串字读。

**代价：位置空间被压缩，token 数 ≠ 位置数。** 上例 9 个 token 最大位置只到 6（1D 会到 8）。卡 2 实测的放大版：A 段 **177 个 token（含 144 图像 token=12×12 网格），最大位置只到 44**，正确续位是 **45 而非 177**。

**于是卡 2 三个变体的对错一目了然**：

| 变体 | 错在哪 | 实测 |
|---|---|---|
| (a) 不管 | HF 自动推位需要 `input_ids+image_grid_thw` 重算三轴，带 past 续算拿不到 → 回退路径从 **0 重启**；latent 步走 `inputs_embeds` 三轴全塌 [0,0,0] | Δlogit=33.0 |
| (b) 天真 arange(177…) | 1D 直觉"token 数=位置数"在 M-RoPE 上不成立：正确是 45，给 177 等于凭空插了 132 的假距离 | Δ=19.3 |
| (c) 金标准三轴切片 | 用全序列 `get_rope_index` 的真三轴位置 | ✅ top-1 100% |

一句话：**1D 世界里"第几个 token"和"什么位置"是同一件事，append 天然正确；M-RoPE 把位置变成 (时刻,行,列) 且图像按"面"占位，两件事从此分家**——任何按 token 数续位的代码（包括 LatentMAS 搭的便车）都会在这里静默翻车。Qwen 系接管模块要做的：续算时自己维护"当前最大坐标"，文字按 max+1 三轴同值续、新图按网格铺。

## §6 卡3 — 底稿里到底有没有图？（生死线，1 天）

### 为什么要有这张卡

前两张卡管的是"底稿格式对不对"，这张管的是**底稿里有没有干货**——这是整个项目的生死线：

> **桥句 4**：如果图的信息根本过不了 KV 通道，那格式再对、工程再漂亮都没有意义。

### 设计：盲考 + 四个对照组

考题用 **POPE** 数据集："图里有没有狗？"这类是/否题，对错各半，**盲猜正好 50%**——问题本身不泄露答案，答对只能靠图。取 1000 题。

五个臂，同一批题：

| 臂 | 比喻 | 谁看图 | A2 收到什么 |
|---|---|---|---|
| **U（上界）** | 开卷 | A2 自己看图 | 图 + 题 |
| **L（下界）** | 纯盲猜 | 没人 | 只有题 |
| **T（文字纸条）** | 传统传纸条 | A1 | A1 写的 ≤128 字描述 |
| **X（思维底稿）** | LatentMAS | A1 | A1 的 KV（含 $m=10$ 页默想）,**不见图不见字** |
| **XWa** | 底稿+翻译器 | A1 | 同 X，但开了真 $W_a$ |

夹逼逻辑：X 的成绩必然落在 L（什么都没收到）和 U（亲眼看图）之间。**X 比 L 高出多少，就是 KV 通道实际传过去的视觉信息量。**

### 判决表（配对 McNemar 检验，n=1000）

| 结果 | 判决 |
|---|---|
| X − L > 5 个百分点，p<0.01 | **通道有效**，项目成立，继续卡4 |
| 2~5 个百分点之间 | 边缘 → 先做改进（共享视觉前缀）再复测 |
| X − L < 2 个百分点 | **通道传不动视觉信息** → 触发止损：转"负面结论+诊断"论文 |
| X > T | 强结论：底稿比纸条好使，可当主卖点 |

顺带记录两个"体检指标"：A2 的回答里有没有"我看不到图"这类拒答（直接暴露底稿里没图），以及 $m$ 从 0 扫到 20 的趋势（$m=0$ 时 A2 连 A1 的读图底稿都拿不到吗？不——$m=0$ 只是没有默想页，读图的底稿还在。真正的空白对照是 L）。

### 为什么 A2 绝对不能看图

这是这张卡最容易设计错的地方：如果 A2 也看图，它自己就知道答案，**你测的就不再是"通道传了多少"，而是"A2 自己看图的能力"**——通道即使全断，分数也不会掉。盲考是唯一能把"通道贡献"单独剥出来的办法。

## §7 卡4 — 涨分是真读懂了，还是安慰剂？（半天，复用卡3代码）

### 为什么要有这张卡

设想卡3 结果是 X=68%、L=55%，差 13 个点，很漂亮。**但这还不能庆祝。** 已有工作（arXiv 2607.26773）实测过：latent 消息的收益可以来自"消息**存在**"而非"消息**内容**"——多出来的那几百个 KV 位置本身就会改变模型的解码状态，哪怕里面装的是无关内容。

> **桥句 5**：要证明"读了底稿才会做题"，必须让他拿着**别人的底稿**再考一次——如果分数不掉，说明他根本没读。

### 设计：换底稿，其余全不动

卡3 的 X 臂原样重跑，只换 A2 拿到的底稿：

| 臂 | 换成什么 | 检验什么 |
|---|---|---|
| **Xshuf** | **上一道题**（别的图）的真底稿 | 内容错了但格式/统计全对——**主对照** |
| **Xrand** | 逐层匹配均值方差的高斯噪声 | 连"真底稿的统计性质"都没有 |
| **Xlat** | 只留 $m$ 页默想、丢掉读图部分 | 干货在默想页还是读图页？ |
| **Xprm** | 只留读图部分、丢掉默想页 | 同上，反向 |

### 判决表

| 结果 | 结论 |
|---|---|
| X − Xshuf > 4 个百分点 | 收益确实来自**内容** ✅ |
| X − Xshuf < 1.5 个百分点 | **安慰剂** ❌——止损线：整个通道是假的 |
| Xlat ≈ X | 干货全在默想页 → "只传默想页"成为最省显存的改进方向 |
| Xprm ≈ X 而 Xlat ≈ L | 默想是无效的，$m$ 步 latent 可以整个砍掉 |

这张卡**四篇相近论文一篇都没做**。无论结果正反，都能单独成文里的一节。

### 为什么需要 620 题这个量级

判 5 个百分点的差异不是拍脑袋：配对二值实验里，能提供信息的只有"两臂一对一错"的题（discordant pairs）。按 20% 的 discordant 率算，**检出 5 个百分点需要约 620 题；只有 60 题的话，16 个百分点以下的差异统计上根本看不见**。所以 n=1000、报 discordant 对数、用 McNemar 精确检验——这三件事是绑定的。

## §8 追问区（预判的坑）

**Q1：为什么不先修好 Qwen 的页码再跑卡3？**
修页码是工程，跑 LLaVA 是绕开。先在没有页码问题的模型上确认"机制本身行不行"（卡3），再回头处理页码（那是改进阶段的活）。反过来做的话，修页码的两天可能白花——万一机制本身就不行呢。

**Q2：X 臂的 A2 看不到图也看不到字，它怎么知道该答什么？**
A2 自己的提问文字（"图里有狗吗？请答 yes/no"）是正常给的。它缺的只是**关于图的信息**——这正是要测的东西：这块缺口能不能被 A1 的底稿填上。

**Q3：为什么 Xshuf 用"别的题的底稿"而不是只用随机数？**
两个都要。Xshuf 的底稿是**真底稿**（统计性质、格式全对），只是内容对不上这道题——它单独隔离"内容"这个变量。Xrand 连统计性质都不对。如果出现 Xrand < Xshuf < X 的阶梯，说明"格式效应"和"内容效应"都存在，各占多少一目了然。

**Q4：m=10 是哪来的？**
LatentMAS 论文的常用档（0~80 可调）。注意代码默认 m=0（[run.py:102](../../run.py#L102)），跑的时候必须显式传——这是我们在源码解析里抓到的坑，example log 里有一份就是 m=0 的退化样例。

**Q5：卡1 说 $W_a$ 默认是单位阵，那卡3 的 XWa 臂还测什么？**
测"开了它会不会更好"。默认关 ≠ 开了没用——LLaVA 的语言骨干是 Vicuna（词表输入输出矩阵不共享），$W_a$ 在它身上是非平凡的，这一臂给"$W_a$ 对视觉信息有无贡献"一个直接数字。

**Q6a：位置编码是何时加进去的？LatentMAS 怎么处理的？**
不在 embedding 阶段——RoPE 在每层注意力算分时把 Q/K 按位置旋转注入，K 入 cache 时角度已固化。LatentMAS 没有显式处理，搭的是 HF"位置=past 长度接着数"的便车，1D RoPE 下恰好正确。详见 §5"深入一层"。

**Q6b：M-RoPE 三轴和 1D 差在哪？**
1D：一个 token 一个排队号；M-RoPE：一个 token 三个坐标 (时刻,行,列)，图像整图共用一个 t、h/w 按网格填、后续文字从"最大坐标+1"续 → 位置空间被压缩（实测 177 token 最大位置 44）。任何按 token 数续位的代码在此静默翻车。手算例与三变体对照见 §5"深入一层"。

**Q6：这四张卡跑完，能发论文吗？**
卡1+卡2 是方法节的素材（尤其页码问题——四篇已有工作没人写过）；卡3+卡4 无论正负都是核心实验：正 → "免训练多模态 latent 通信可行"；负 → "为什么不可行：一个诊断"。设计时就保证了**两个方向都有产出**，这是止损线的意义。

## §9 术语表

| 术语 | 一句话 |
|---|---|
| KV cache | 模型读每个字时在每层存下的中间结果（"思维底稿"），后面的字靠注意力回看它 |
| latent steps ($m$) | 不吐字、把最后一层思维向量喂回自己、多想 $m$ 轮（"闭卷默想 $m$ 页"） |
| $W_a$ | 把思维向量翻译回输入格式的矩阵（"翻译器"）；代码默认是单位阵=空转 |
| RoPE / M-RoPE | 位置编码：不加在输入嵌入上，而是每层注意力时把 Q/K 按位置旋转角注入；**K 入 cache 时角度已烤进去**。M-RoPE 是三轴 (t,h,w) 页码（Qwen-VL 系），图像按"面"占位 → token 数 ≠ 位置数（详见 §5 深入一层） |
| POPE | "图里有没有 X"的是/否题库，盲猜 50%，专测看图能力 |
| 上界/下界 | 亲眼看图的成绩 / 什么都没收到的成绩；通道的贡献夹在两者之间 |
| 安慰剂对照 | 把底稿换成无关内容重考一遍，分数不掉=没读底稿 |
| 载荷 / 视觉载荷 | 传输内容里"下游真正用得上的货"（视觉载荷=关于图的情报）。**载体≠载荷**：KV 页可以占着位置影响解码（载体在）却不含图的情报（载荷空）。只能靠对照测：撕掉不掉分=无载荷（默想页）；换成错图的版本分数暴跌=有载荷（图像 KV） |
| McNemar / discordant | 配对检验：只数"两臂一对一错"的题；这种题少于 20 道时结论不可信 |

## §10 进阶（跳过不影响理解）

**与四篇已有工作的关系**：L²-VMAS / ViF / MACF / Vision Wormhole 都做了"多模态 + latent 通信"，但全部需要训练，且**没有一篇做过卡4 的安慰剂对照、没有一篇报告"LatentMAS 原样搬过来是多少分"**。四张卡的产出正好填这两个空。详见 [research-digest.md](research-digest.md) §2。

**CAG（内容归因增益）**：卡4 的 X − Xshuf 差值，学名叫 CAG。已有实测显示总准确率变化可以被"存在效应"和"内容效应"两个反向分量合成（ΔAcc=−1.00 却 CAG=+5.17），所以主指标必须是 CAG 而不是准确率差。详见 [papers/research-2026-08-01/21_evaluation-protocol.md](../papers/research-2026-08-01/21_evaluation-protocol.md)。

**判决之后的三条路**：全过 → 扩展到完整 4-agent 主表（卡5，见 [papers/research-2026-08-01/31_experiment-cards-trainingfree.md](../papers/research-2026-08-01/31_experiment-cards-trainingfree.md)）；卡3 边缘 → 先做共享视觉前缀改进再复测；卡3/卡4 证伪 → 负面结论+诊断成文。
