# Q&A 03：文本 embedding 在自己的 top-256 主子空间里，占比会不会也很低？——卡 1 缺失的阳性对照

> **日期**：2026-08-03 · **模式**：问答（实验卡先记，待窗口执行）
> **问题来源**（用户原述）：有没有可能文本 embedding 在文本 top-256 主子空间的能量占比也很少？
> **性质**：对卡 1 测量二的**方法学挑战**，指出一个真实缺口——只测了视觉占比与随机基线，未报"文本自己占多少"这个阳性对照。

---

## 数学事实

文本 embedding 在自己 top-256 主子空间的平均能量占比 = **PCA 解释方差比**（前 256 特征值和 ÷ 总和）。保证：①必然 ≥ 随机基线 6.25%（PCA 最优性；等号仅当完全各向同性）；②它是一切 256 维子空间里的**最大**可达占比。但 "≥ 6.25%" 不保证"很大"——可能 50% 也可能 10%，**本项目未测**。

## 结论强度分档（取决于这个未测的数）

| 文本自身占比 | "薄饼"比喻 | "视觉在薄饼外" |
|---|---|---|
| 高（>40%） | 实 | **强**：文本高度集中、视觉恰为随机水平 → 两个世界成立 |
| 中（15-30%） | 半实 | "完全正交"降为"显著更分散" |
| 低（≈6.25%） | **没有薄饼**（文本近各向同性） | 退化——但弱化版仍立：视觉占比**精确=随机基线** → "视觉与文本主结构统计独立"不受影响 |

文献预期偏"高"（embedding 各向异性：all-but-the-top、representation degeneration/narrow cone），但旧模型观察不替代本项目 backbone 的测量。

## 同型的第二个缺口

卡 1 报了"视觉→最近文本嵌入 cos=0.079"，未报**文本→最近其他文本嵌入 cos** 对照。若文本互相的最近邻也仅 ~0.1（高维稀疏下可能），0.079 就不算"远"。

## 实验卡 E4（约 5 分钟，待实验窗口）

```
E4-a  文本自谱占比: pca_lowrank 的奇异值平方即特征值 → Σtop256/Σ全部   （两行）
E4-b  文本-文本最近邻 cos: 抽 1000 行 × 全表, 排除自身                 （一次矩阵乘）
模型:  llava-onevision-qwen2-7b-ov-hf + Qwen3-VL-8B（现役双主力）
判决:  E4-a ≫ 6.25% 且 E4-b ≫ 0.08 → 卡1"两个世界"结论原样保留
       任一接近视觉水平            → 降格为"统计独立"弱化版, 撤"薄饼"修辞
```

## ✅ E4 已补测（2026-08-03，`e4_positive_control.py`，结果 `e4_results.json`）

| | 基线 | **文本自谱占比** | 视觉占比 | **文本-文本 NN** | 视觉-文本 NN |
|---|---|---|---|---|---|
| LLaVA-1.5 | 0.0625 | **0.235**(3.8×) | 0.058 | **0.348** | 0.082 |
| LLaVA-OV | 0.0714 | **0.398**(5.6×) | 0.074 | **0.329** | 0.078 |
| Qwen3-VL | 0.0625 | **0.187**(3.0×) | 0.108 | **0.235** | 0.090 |

**判决：两项阳性对照均过，"两个世界"方向性保留 + 量化修正**：
1. 文本自身占比 3.0-5.6× 基线（落中档 19-40%）——**薄饼存在但为"中等厚度"，"完全正交"改为量化表述**：视觉对文本主子空间的偏好为随机水平（LLaVA 系）或弱（Qwen3-VL），文本自身集中度为其 1.7-5.4 倍；
2. 文本互邻（0.24-0.35）比视觉到文本最近邻（0.08-0.09）近 **3-4 倍**——0.079 确实算"远"；
3. 复测一致：LLaVA-1.5 视觉占比 0.058 ≈ 卡 1 的 0.060 ✓；
4. **新 nuance**：Qwen3-VL 视觉占比 0.108=1.7×基线——不像 LLaVA 系精确随机，其 projector 对文本主结构有**弱非零偏好**（仍远低于文本自身 0.187）。"统计独立"对 LLaVA 系严格成立、对 Qwen3-VL 放宽为"弱对齐"。
