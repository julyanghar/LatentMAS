# VideoAgent × Latent Collaboration —— 路线计划

> **版本**：v2（2026-08-05 重写理顺；v1 存 `../TRASH/00-plan-v1-superseded-20260805.md`，作废勿引）· **状态**：判死实验尚未开跑，下一步是 H 卡预检（§6.4）。
>
> **这份文档怎么读**：它是整个项目的**脊柱**——只放决定、判死点和排期，细节全部指向编号文档。§1–§2 讲我们要做什么、立论还剩多少；⭐ **§3 判死体系是全文最重要的一章**；§4–§5 讲方法；§6 讲在哪做；§7 排期；§8 写论文的红线。**只想知道"下一步干什么"→ 直接看 §7 和 §10。**
>
> **全文的比喻**：把这个项目想成一台**换管道手术**。病人（现有视频 agentic 框架）体内有一根**文字管道**——看图的模型把看到的写成 caption，传给推理的模型。我们的手术是**把这根文字管换成 latent 管**（传向量不传字），其余器官一概不动。手术前要先确认两件事：**这根文字管真的在漏（§3 判死），新管子装得上（§4–§5）**。

## TL;DR

1. **做什么**：在已有的视频理解 agentic workflow 上，把 viewer（视觉模型）→ reasoner（纯文本推理模型）之间的 caption 边换成 latent 通道，要求在多个框架上有效。**大概率要训一个 ~21M 的 adapter。**
2. **目标已放宽（2026-08-05 用户裁定，§2.1）**：主主张 = **在现有 VideoMAS 的 viewer→reasoner「盲文字边」上，换 latent 能涨分**（存在性主张、全格报告；有利先验：C1 盲文字臂 +15.8~+17.3、MACF +13.7~18.6——不对称设定正是文献里 latent 赢的那半）；**副主张 = 效率**。"latent 更保真"仍不当前提（§8.1-2），当被检假设；**C 臂从潜在判死改为 gap-closure 分母，判死规则一条没动**。
3. **所有开发排在判死之后**：四级 D0 探针 + 五臂对照 + 1 小时免训练判死，多数不用写一行 latent 代码。**其中最便宜的几个实验，任何一个翻车都能终结整个项目——所以先跑它们。**

## 1. 我们要做什么

```
                     ┌─────────────────────┐
   视频帧 ──────────► │ viewer = 视觉模型     │
                     │ (Qwen3-VL-8B)        │
                     └──────────┬───────────┘
                                │  ⭐ 手术位置：latent，不是 caption
                                ▼
                     ┌──────────────────────┐
                     │ reasoner = 纯文本推理模型│ ──► 决定下一批看哪几帧 / 出答案
                     │ (Qwen3-8B-Thinking)   │
                     └──────────────────────┘
                                │  循环，最多 N 轮（取帧请求保持文字）
```

**三条硬要求，各自的依据**：

| 要求 | 依据 |
|---|---|
| ① reasoner 是**纯文本推理模型**（不用 VLM 当脑） | **三份独立证据说"换脑比换通道值钱一个量级"**：VideoAgent 消融（换 GPT-3.5→GPT-4 **+11.4**，文字通道加宽 10.3 倍只 **+0.6**）· MemDreamer Table 6（换推理模型动 **10.0/12.1**，换感知模型只动 0.4~2.5；解耦后推理力与成绩相关性 R 0.702→**0.897**）· SportMV-Agent 消融（换 orchestrator **−10.99%**，换感知工具 +0.41%） |
| ② 建在**已有** workflow 上 | 手术对照的前提：骨架不动、只换管道，涨跌才能归因到通道。⭐ **host 都用 caption 交流不是缺陷，是入选条件**——没有文字管就没东西可换（[04 §7.0](04-host-frameworks-explained.md)） |
| ③ 在**多个**框架上有效 | 把工作从"一个系统的 hack"变成"可插拔的通道"；这条线没有共同 benchmark、没有 head-to-head 协议（[Q&A/06](../Q&A/06-latent-collab-design-space-and-brain-tool-edge.md)） |

**用户前提判断（2026-08-04 裁定，§4 给证据）**：大概率需要训练；直接套 LatentMAS 免训练做法大概率不行，尤其跨架构。

## 2. 立论的现状：诚实定位

> 这一章回答：**先例审计（[01](01-prior-art-audit.md)/[02](02-navgpt2-and-sterner-explained.md)/[03](03-eight-risk-papers-explained.md)）之后，这个 idea 还剩下什么？** 结论决定了整个计划"先证伪、后开发"的排法。

**新颖性只剩两个合取项**（原来准备写的两条"没人做过"都被 2024 年的旧论文推翻，细节见 01）：

```
(a) 发送方是会推理的 agent，不是接收方自己的感知前端
(d) 多轮循环里，纯文本接收方决定 viewer 下一步看什么
```

**而且先验不乐观**：(d) 的两个邻居格子都测过——"语言决策 + caption"最好 43 分（DiscussNav），"隐状态 + 浅层读出头"21.46 分（NavGPT-2 Table 5）；我们那格（语言决策 + latent）无人测量，**空着，但夹在两个不高的数中间**。

### 2.1 目标放宽（2026-08-05 用户裁定）

> **放宽后的成功标准**：对现有 VideoMAS，只要 viewer-VLM ↔ reasoner-LLM 之间"文字→latent"的替换**能涨分**，即证明方法价值——不再要求打赢所有替代方案（帕累托）。
> 📌 **通俗版（追问回填）**：目标从"证明装我们零件的车是**全市场最优**"改成"证明对**已经在路上的这批车**，换上我们的零件跑得更快"——**改装件供应商，不争整车冠军**。为什么合理：VideoMAS 的 reasoner 是**天生的瞎子**（无视觉塔，给图也看不了），适用先验是 C1"下游是瞎子"那组 +15~17，不是"人人看得见"那组打平；latent 赢过的战场全是瞎子场合。三条护栏的白话：①**不能挑着报**（10 格全报，防"彩票中奖"）；②**涨分验明正身**（换全零/随机 latent 再跑，涨幅还在才算真——有论文拆过 +15 里 8 分是安慰剂）；③**C 臂从考官变尺子**（报"帮瞎子把文字↔看图的差距补回几成"；C 赢不死，因为"最会推理的脑恰恰都是瞎的"有三份证据顶着）。**放宽的是及格线，不是体检项目**——C−D≈0（文字管根本没漏）和 A−D≤0（文本脑不占优）两条死刑条款照旧。

**为什么可以放宽（三个理由）**：

1. ⭐ **C1-rev 的"修正"反过来支持它**：当时给下游睁眼（textsighted）后 latent 优势塌掉——但 **VideoMAS 的 reasoner 是结构性失明的**（无视觉塔，想睁也睁不了）。适用于 VideoMAS 的先验不是 textsighted 那行（+1.2/−4.7/…），而是**盲文字臂那行：Latent−Text(blind) = +15.8/+11.4/+17.3/+12.3**。⚠️ 打折条款：C1 的 latent 是同模型 KV、无跨模型翻译损失，B 臂要过 adapter——**上界味先验，非承诺**。
2. **不对称设定正是文献里 latent 赢的那半**：MACF +13.7~18.6（视频）、LACO 单调（驾驶）；所有负结果（Sterner 单次、HyLaT、C1-textsighted）都在"接收方看得见/对称"的设定。放宽 = 退到有利地形。
3. **主张形状有先例**：Latent Bridge 的 *"never significantly worse … significantly better on 2 of 7"* 就是这种存在性主张，带代码发表。

**三条护栏（缺一条各有一种死法）**：

| # | 护栏 | 不钉会怎么死 |
|---|---|---|
| 1 | **全格报告**：所有 host × benchmark 全报；主张写成"**从不显著更差 + 在 K/N 格显著更好**" | "存在"被读成挑格子（Latent Bridge 连 greedy 下 4 胜都自降为 2 胜） |
| 2 | **可归因**：CAG + 桥替换（零/随机向量）+ 双尺寸接收方（§7.2） | CausalAudit：+15 里可有 8.33 是"给别的题的消息也能拿到"；4B/8B 反转 |
| 3 | **C 臂照跑照报，角色改分母**：成功度量 = **gap closure = (B−A)/(C−A)** | 不跑 C=藏对照；跑了 C 赢也不杀——"坚持文本脑"有三份独立证据 + LinguDistill（VLM 化伤语言力）撑 |

**判死规则一条没动**（放宽的是成功标准，不是证伪标准）：`C−D≈0`（文字管不漏→无 headroom）与 `A−D≤0`（文本脑不占优→前提崩）照旧判死。

**卖点排序（放宽后）**：

1. **主**：盲文字边上换 latent 的**准确率增益**（全格报告 + 归因 + gap closure）
2. **副**：效率——省 caption 生成 token + 不重编码已看过帧（对手 SPARC，§7.2）
3. **底线结果也可发**：若增益≈0 但效率大赚 → 退回帕累托表述（"同分省算力"）——**两扇门都留着，五臂设计天然同时覆盖**

### 2.2 优先级裁定（2026-08-05 二次，用户）：先拿 B > A 首胜信号，护栏后置

> 用户原话："三个护栏都有道理，但先不需要考虑这么复杂，**先确认 latent 通道能比 text 通道强才是最重要的**。"

- **首要里程碑**：一个 host × 一个库上，**B vs A 显著**（n≈500，McNemar）。
- **护栏全部推迟到写作/加固阶段**（全格报告、CAG、双尺寸、gap-closure）。
- **只留两样，因为它们不是护栏、是对比成立的前提**：① **统一 viewer**（A 的 caption 与 B 的 latent 必须同出 Qwen3-VL-8B，否则 B vs A 比的不是通道）；② **零向量对照**（把 latent 换全零/随机再跑一遍——防自欺不防审稿，成本一次推理）。
- **判死点角色调整**：C−D / D0 探针从"开发前关卡"降级为"**B 首败后的诊断包**"（B 输了没法直接判死——可能只是 adapter 没训好；这时 D0-a/b/c/d 与 C−D 逐级定位输在哪）。γ 仍可随时跑（1 GPU·h）。
- ⚠️ **接受的风险，写明**：旧排序花 2 天便宜实验保护 adapter 投入；新排序**接受"若文字管其实不漏、~10 GPU·h + 2 天工程白费"的风险，换最快的头条信号**。用户裁定接受。
- **判读不对称性**：**B 赢 = 信息量大（头条到手）；B 输 = 信息量小（进诊断包，不判死）**。
- **效率账整体后置（同日追加裁定）**：vLLM 迁移、prompt_embeds 吞吐验证、SPARC 对比全部等 B>A 确认后再做——**现在的工作面只有阶段 0 + 首胜实验，全 HF**。若首胜结果是 B≈A，"效率救场"（退帕累托表述）是届时的决策点，不提前投入。

## 3. ⭐ 判死体系（排在所有开发之前）

> 这一章回答：**这个 idea 可能不成立的每一种方式，各用哪个最便宜的实验去检验？** 排序原则：便宜 × 致命，越靠前越先跑。
>
> ⚠️ **2026-08-05 角色调整（§2.2）**：本章从"开发前关卡"改为**两用**——γ 照旧随时可跑；**D0 探针与五臂 C−D/A−D 降级为"B 首败后的诊断包"**。首胜实验（B vs A）提前到它们前面。

### 3.0 总览：七个判死点

| # | 判死点 | 检验什么病 | 成本 | 要 adapter 吗 |
|---|---|---|---|---|
| **D0-a** 复述探针 | reasoner 能只凭 latent **复述**帧内容吗？不能 → **看不懂**（桥设计错，回 §5 换桥） | 小时级 | ❌ |
| **D0-b** 示范探针 | 给 1~2 道 in-context 示范后，latent 臂**追上** caption 臂吗？追不上 → **信息没传到** → 止损 | 小时级 | ❌ |
| **五臂 C−D** | 同一个模型，看原图 vs 读 caption——**文字管到底漏不漏**？≈0 → 立论崩 | ~2 天 | ❌ |
| **五臂 A−D** | 文本推理脑真的比 VLM 脑强吗？≤0 → 理想态作废，退回同模型双角色 | （同上一批跑） | ❌ |
| **实验 γ** | 免训练直接塞 KV 行不行？行 → 不用训了（不太可能，见 §4） | 1 GPU·h | ❌ |
| **重构上界** | m=32 个向量装得下一帧的 caption 级信息吗？装不下 → 上界低于文字 → 止损 | 半天 | ❌ |
| **D0-c** 训练单调性 | latent−caption 的 gap 随训练**单调缩小**吗？不缩 → 训练目标选错 → 止损 | 训练中挂监控 | ✅ |
| **D0-d** 反解阶梯 | 伪 token 的信息**能不能被文字装下**（三臂：最近词 / 软叠加 / 原样） | 半天 | ⚠️ 粗训即可 |

**为什么 D0 拆成 a/b/c/d 四级**（推理链见 [02 §C.4](02-navgpt2-and-sterner-explained.md)）：Sterner 的证据指向病因是"**信息在，但接收方不会用**"而非"看不懂"——**不会用可训练、看不懂要换桥、没传到要止损，三种病三种药，必须先分清**。D0-d 的判读单独记：

```
raw ≈ soft ≈ hard   →  文字装得下 → 通道优势是假的 → 止损
raw ≈ soft ≫ hard   →  信息在叠加权重里 → 优势真，但 CIPHER 级简单通道可能就够
raw ≫ soft          →  信息在词嵌入凸包之外 → 「超语言」的最强证据
（hard=最近词 one-hot；soft=softmax(e·Eᵀ/τ)·E 投回词嵌入凸包；raw=原样。
 用输入嵌入矩阵而非 lm_head，先查 tie_word_embeddings；τ 要扫）
```

### 3.1 五臂对照（一行 latent 代码都不用写的立论验证）

所有臂共用 host 的原生循环（以 VideoAgent 为例，循环细节见 [05 §2](05-videoagent-workflow-source-analysis.md)），唯一差别是 **reasoner 收到什么**：

| 臂 | reasoner | 收到 |
|---|---|---|
| **A** 现状 | Qwen3-8B-Thinking | caption **纯文字** |
| ⭐ **T+** 软文字（2026-08-05 用户提出，CIPHER 式） | Qwen3-8B-Thinking | **与 A 同一条 greedy caption 轨迹**，但每个位置传 **top-k 分布的软嵌入 Σp·E_receiver**——**免训练、免 adapter、免疫漂移**（p 锚在共享词表上，两家 vocab=151936 同 tokenizer） |
| **D** 控制组 | Qwen3-VL-8B（不给图） | **与 A 逐字相同的文字**——只换读它的模型 |
| **C** 杀手控制 | Qwen3-VL-8B | **选中帧的原图** |
| **A′** 先知上界 | Qwen3-8B-Thinking | **captioner 事先知道题目**写的 caption |
| **B** 我们的 | Qwen3-8B-Thinking | 经 adapter 的**伪 token** |

**四个减法各回答一个问题**：

```
⭐ C − D    文字管到底漏多少（reasoner 能力被控住的干净测量）
⭐ C − A    "干脆换个 VLM 当脑"总共值多少（这个数太大 → 要 latent 干什么）
   A − D    文本推理脑比 VLM 脑强多少（验证硬要求①）
   A′ − A   文字管里"不知道会被问什么"造成的那部分漏损（latent 能补的主要就是这块）
⭐ T+ − A   离散化本身丢多少（token 骨架逐字相同，唯一变量=亚军概率质量）
            ——比 Sterner 还干净的对照；T+>A 则 motivation 免训练即证
⭐ B − T+   输出分布之外的信息值多少 = adapter 的存在理由
            ——审稿人问"CIPHER 就够了要 adapter 干嘛"的答案就在这格
```

**信息阶梯**：`A (one-hot) < T+ (分布) < B (adapter latent)`——T+ 比 A 多"每个位置的犹豫"（棕白相间被压成白时，"棕"的概率质量还在 p 里）；B 比 T+ 多"caption 压根没说出来的东西"（pre-readout 视觉状态）。**T+ 三结果都有信息量**：>A=离散化在丢分（大礼）；≈A=B 的靶子更清晰；B>T+=21M 参数的存在理由。
**T+ 工程钉**：top-k 稀疏传输（k≈64）；模板/控制 token 保持硬；receiver 未见过混合嵌入（凸包内但训练分布外，Soft Thinking 证明单跳零样本可容忍；HyLaT 漂移警告是多轮场景）。**与 D0-d 区分**：D0-d 是 adapter 输出的事后投影（诊断），T+ 是 sender 自己的解码分布（独立通道臂）。**先例**：机制=CIPHER（必须引，它自己要求共享词表）；我们的贡献形态是"臂"不是"传分布"这个主张。
**同场判死的姊妹想法**（用户同日提出，记录在案）：把 LatentMAS 的 latent thinking（M1 默想）换成 CIPHER 配方——❌ 两重判死：(1) "自己喂自己 softmax(logits)·E" 逐字 = **Soft Thinking**（已发表；COCONUT 喂 h、LatentMAS 喂对齐后的 h、Soft Thinking 喂概率加权词嵌入——第三格有主）；(2) **M1 多模态零载荷四重复现**（C1：m=0 vs m=10 = +0.9/+0.7/−0.3/−0.1 全 n.s.——文本里默想是空白草稿纸上打草稿，多模态里图像 token 本身就是一大叠算好的草稿），B 臂设计里**没有默想槽位**。一句话：**换引擎烧什么油的争论只在引擎接着轮子的世界里有意义**；T+ 立住是因为它把同一杯"鸡尾酒"从喂自己改成了喂别人——通信边实测接着轮子（盲文字臂 ±15 分动静）。

**判死规则（预先写死，不得事后放宽）**：`C−D ≈ 0` 或 `A−D ≤ 0` → 立论崩；`A′≈A` → 预期缺口为零，重估。

⚠️ **一个必须记住的反转**：**C 不是免费上界**——它每轮每帧付完整视觉编码，算力可能是 A 的数倍。**目标放宽（§2.1）后 C 的角色进一步明确：它不是要打赢的对手，是 gap-closure 的分母**——报 (B−A)/(C−A)，即"文字→像素的差距里，latent 替文本 reasoner 补回了几成"。C 赢不判死；判死的只有 C−D≈0 与 A−D≤0。

⚠️ **已有证据的方向不乐观，所以更要测**：TAMA（唯一直接测量"工具返回图 vs 返回 caption"）均值 +2.68、SE 1.37、**分不出与零**；MemDreamer 的纯文字图记忆比整段像素喂进去还高 8.7~21.2（但它混淆了通道与上下文预算，E4(d)——**我们的 C 臂才是干净版**）。

### 3.2 实验 γ：1 小时判死免训练

```
数据：GSM8K 200 条纯文本提示（无图 → 对免训练最有利的情形）
A 参照：Qwen3-8B 自己 prefill 自己解码
B 朴素：Qwen3-VL-8B 无图 prefill 同一提示 → dump 逐层 K/V → 逐字装进 Qwen3-8B 解码
C 修复：同 B，但 key 先按 5e6 反旋、再按 1e6 重旋（§4 的位置修正）
判死：B 崩且 C 救不回（top-1 < 90%）→ 免训练路线关闭，进 §5
```

**为什么明知大概率崩还要跑**："我们测了，免训练在此不成立"是论文里可写的一段，比直接上训练有说服力；且只花 1 GPU 小时。

## 4. 为什么大概率必须训练

> 这一章回答：**为什么不能把 viewer 的 KV 直接塞给 reasoner？** 比喻：两个人交接班，前一个人留下一本工作笔记，交接成功需要三件事——**本子插得进去（形状）、页码对得上（位置）、字认得出（内容）**。实测结论：前两件过了，第三件过不了。

### 4.1 本机漂移探针（六行）

| # | 探针 | 数字 | 白话 |
|---|---|---|---|
| ① | KV 几何 | ✅ 36 层 / 4096 / 8 KV 头 / head_dim 128 完全一致 | 本子插得进去，1:1 直接装——这条路值得试的原因 |
| ② | M-RoPE vs 1D | ✅ `max abs diff = 0.0` | 伪问题：纯文字 token 三轴精确退化成一维 |
| ③ | `rope_theta` 5e6 vs 1e6 | ❌ 位置超 ~64 就退相关（cos 0.713） | 两把量程不同的尺子；**但确定性可修**——按 5e6 反旋再按 1e6 重旋，不用学 |
| ④ | k/v_proj 权重漂移 | ❌ **15–27%**，是模型自身后训练漂移（6–10%）的 2.3–2.7 倍，随层加深单调增大 | ⭐ **真正的坎**：同一个符号在两人心里不是一个意思 |
| ⑤ | 端到端 | ❌ 真实提示只过第 0 层，V-cache 相对误差已 **31.9%** | 零件装起来测：最浅层就三成误差，后面还有 35 层 |
| ⑥ | chat 控制符 | ❌ `<\|im_start\|>` 漂 **54%/57%**（普通 token 16–20%） | 最需要对齐的结构支架处，误差最大 |

**量级参照**：DroidSpeak 测过"朴素 KV 复用掉 >50% 准确率"的区间，我们的漂移已超过那个水平——**不是试试能不能凑合，是已经知道凑合不了**。

### 4.2 两个比漂移更硬的补充

1. **结构性障碍**：纯文本 LLM 的权重从没见过视觉向量。把视觉 latent 交给它 = 要求它免费完成 BLIP-2 那个 projector 靠训练才学会的事。
2. ⚠️ **位置修好也不够**（ChronoStitch 实测，**同一个模型内**）：三轴重定基把第 0 层 key 修到机器精度（3.6e-8），顺序探针反而 41.7%（比不修还差），要**重算 25~35% 的 token** 才回到上界——**"positions are necessary, but not sufficient"**。我们跨模型只会更糟。→ §3.0 表里"位置=确定性可修"指的是那步算术本身，**不是说修完位置就完了**。

**文献旁证**：每一个免训练 latent 方法都要求同架构；每一个跨家族方法都训了转换器；4/4 同时测两者的论文里**训过的全面吊打免训练的**（MACF +4.7~8.3 / DiffMAS +20 / HyLaT / VW 弱监督版转负）。

## 5. adapter 怎么做

> 这一章回答：**新管道本身长什么样？** 四个设计选择：注入点、读料、输出头、训练信号。

### 5.1 要解决三件事

| # | 问题 | 现状 |
|---|---|---|
| 形状 | 能否直接装 | ✅ 免费（§4.1 ①） |
| 位置 | rope 底数不同 | ⚠️ 反旋+重旋确定性可修，**但必要非充分**（§4.2） |
| ⭐ 内容 | reasoner 没见过视觉向量 | ❌ **唯一需要学的部分** |

### 5.2 注入点：输入层（唯一在纯文本接收方上被验证过的）

| 注入点 | 先例 | 判定 |
|---|---|---|
| (i) 逐层 KV 前缀 | LatentMAS/LACO（同架构） | ⚠️ 纯文本模型上无先例：前 0..l−1 层没参与生成这些 K/V |
| (ii) 加性融合 | C2C | ⚠️ 同样问题，训练更重 |
| ⭐ **(iii) 输入层伪 token** | **BLIP-2/LLaVA/Frozen 大规模验证** | ✅ **选它**——让 reasoner 用完整 36 层去消化 |

第三方背书 + 警告（Latent Bridge 的 v1→v2 教训）：挑 2 层做 cross-attention **离线 KL=0.004 却上线崩**，换输入层 prepend 才 work → **我们的验收必须有端到端臂，不能只看重建指标**。

⚠️ **效率论证在输入层注入下仍成立，但理由要说对**：优势来自**根本不生成文字**（decode 比 prefill 贵 92 倍：10.46 vs 0.114 ms/token@8B/A100——省 150 次 decode ≈1.57s，付 32 次 prefill ≈3.6ms），不是"跳过层"。

### 5.3 读料：双轴扫描（别混两条轴）

**载体**（以什么形式进 reasoner）= 输入层伪 token m≈32 个，与 NavGPT-2/Latent Bridge/BLIP-2 同款——**载体不承担任何新颖性，"我们传 KV"这个说法不成立**（[03 §0.5](03-eight-risk-papers-explained.md)）。
**读料**（adapter 从 viewer 取什么）= 扫描超参：

- **层深** `{浅 4–10 / 中 12–24 / 末层 / 多深度}`，**先验偏中层**——ViF drop study：丢中层关键子集 −59.9 最致命、丢深层只 −2.6~−3.4（内容已迁走）；Latent Bridge 读 24/36 层、MACF 读末层，没人读浅层。（LACO 的"浅层最优"是**载体=直接 KV 注入**时防劫持的结论，约束不到读料。）
- **形式** `{V-only, K+V, h}`——GQA 下 K、V 各 1024 维是 4096 维 h 的有损投影，**读 h 信息上不亏**；选 KV 只是系统理由（KV cache 天然跨轮驻留）。**K 被 RoPE 旋过而 V 没有**，优先读 V 或先反旋 K。

### 5.4 输出头：两个变体平级对比（B 是提案，未验证）

```
主干：m 个可学 query → cross-attend 读料 → 2~6 层小 transformer(d=512) → 投到 4096
参数 ~21M（LCF 量级，约 5 GPU·h 一次配方）
```

| 变体 | 输出 | 一句话 |
|---|---|---|
| **A 自由向量** | m 个任意 4096 维向量 | 表达力无上限；但落在 reasoner 没见过的区域（Phase1"两个世界"实测视觉表示天然不住词嵌入区） |
| **B 软词瓶颈** | `softmax(h·Eᵀ/τ)·E`（E=reasoner 冻结词嵌入，零新增参数） | 消息强制为**母语词嵌入的概率加权和** = trained cross-modal CIPHER：天生在流形上 + 可解释性白送 + τ 连续插值 caption↔latent |
| 判读 | **A≈B → 选 B**（白送可解释性）；**A≫B → 差值=超语言信息的实测大小，本身是主图**。双赢 | |

B 的判死清单：①容量不够（A≫B，不算坏事）②熵塌缩（监控+正则，τ 要扫）③范数收缩（凸组合往均值拉，监控范数比值，必要时加可学增益）④两臂都输 caption（回 D0 止损）。
📌 **不需要对 E 求逆**：软词瓶颈是前向参数化（`h·Eᵀ` 就是一次注意力打分），不是分解；**恰因不可精确求逆才有约束力**——调不出来的那部分就是 D0-d 量的超语言信息。D0-d 的事后投影只是 B 的**下界**（训练后量化 vs 量化感知训练）。

### 5.5 训练信号：对比式为主 + 行为式为辅，两段课程

| 方案 | 目标 | 风险 |
|---|---|---|
| 重构式 | ⭐ **2026-08-05 升级为软蒸馏（用户对"天花板=caption"的质疑触发）**：不对 one-hot caption 算 CE，改逼 reasoner 凭伪 token 念出的**逐位分布贴近 viewer 的逐位 top-k 分布**（KL）——经典 KD 软标签>硬标签 | 天花板从 caption（阶梯第一级 A）抬到 **T+ 水平（第二级）**，第二段再破 T+；MACF Stage1（去掉 −14.9）证明锚定本身必要 |
| 行为式 | 下游答案对错 | 稀疏；有平凡解（学会忽略通道） |
| ⭐ **对比式** | 正=本题 latent，负=**别题 latent** | **把 shuffle 对照写进训练目标**——因果审计实测 +10pp 增益里 +8.13pp 在"消息来自别题"时仍在，对比式是唯一从机制上堵住这个的 |

**必须两段**：纯重建/对齐只治"看不懂"，不治"不会用"（Sterner 的桥只训过 captioning、VQA 上输了）——第二段直接拿**取帧决策/任务成败**当信号（可抄 Mem-W 的 RLOO+二元成败奖励，先用答案 CE 简版）。挂 **ΔL 早停**：500 步不单调上升即杀配方。

> 📌 **通俗版（追问回填）——三个角色一个故事**：📷 摄像师（viewer，冻结哑巴）看帧有印象；✍️ **翻译员（adapter 21M，全场唯一在学的）**把印象写成 32 张只有老师读得懂的"密文便签"；👴 老师（reasoner，冻结）只会读字。**第一课=听写课**：老师只看便签把 caption 一字字念出来，念错扣分——**扣分不改老师，但"在第几张便签读岔的"这个批改意见穿过老师传回翻译员**（=梯度穿过冻结模型）。**第二课=防串卷考试**：拿对便签要答好、拿**别题**便签要答不出（串卷负样本同 batch 白送）——因为实测过 +10 分里 +8 分是"塞别题便签也能涨"的安慰剂，串卷测试在训练里掐死它。**只上听写课必败**（天花板=caption，Sterner 的桥就这么输了 4.5 分）。**红线**：EgoSchema 那 500 道带答案的卷子不许当练习题（背题≠考试）。**省卡**：摄像师印象提前拍照存盘，上课不用到场。

**训练力学与数据纪律（2026-08-05 追问补齐）**：

- **核心机制一句话**：**冻结 ≠ 不传梯度**——损失穿过冻结 reasoner 的 36 层流回 adapter（BLIP-2/Frozen/Sterner 同款，Sterner 原文 *"backpropagate losses through the frozen LLM, updating the mapping network"*）。两端 8B 全冻，只有 21M 在学。
- **一段式样本** =（帧，caption）：③读料（冻结 viewer 中层 V）→ adapter → 32 伪 token → `[伪token]+"Describe:"` → 冻结 reasoner 逐词 CE 复述 caption。**数据=离线资产②直接复用**（EgoSchema 9 万对起步，免费）。
- **二段对比式的负样本白送**：batch 内别题的伪 token 即负样本——逼"本题特定"信息，堵因果审计那 +8.13 安慰剂分量。
- ⚠️ **数据泄漏纪律（新钉）**：**EgoSchema 只有 subset 500 题带答案——严禁用于 Stage 2 训练**（会污染唯一评测集）。钉死：**NExT-QA train 训 → NExT-QA val 测 + EgoSchema 整库当纯测试**（跨库泛化）。
- **读料离线化**：读料是冻结 viewer 的确定性输出 → 离线算好存盘（同帧特征库），**训练时 viewer 不驻卡**，单卡可训。
- **预算**：~5 GPU·h/配方 × 两个输出头变体 ≈ 10 GPU·h；监控三件：D0-c 单调性 + （B 变体）熵塌缩 + 范数收缩。

## 6. Host：在哪做手术

> 这一章回答：**病人选谁？** 判据（用户裁定）：**能否在它身上设计实验验证我们的假设**——比论文数字硬（各家数字都是 GPT-4/4o 引擎跑的，不预测我们 backbone 上的排名）。四候选概览见 [04](04-host-frameworks-explained.md)；两个入选者已完整 clone 并逐行解剖：**[05=VideoAgent](05-videoagent-workflow-source-analysis.md) · [06=VideoHV](06-videohv-workflow-source-analysis.md)**（与 04 冲突处以 05/06 为准）。

### 6.0 模型名册（用户 2026-08-05 裁定，全计划唯一权威）

**两条总则：所有文本 LLM 角色 = Qwen3-8B；所有看图角色 = Qwen3-VL-8B。**

| 角色（原模型） | 钉定 | 备注 |
|---|---|---|
| VideoAgent 大脑（GPT-4-1106-preview） | **Qwen3-8B** | H2 卡 |
| VideoHV 出题人/判官/选答人（OpenAI structured） | **Qwen3-8B** | H3 spike 验 `.parse` 存活率 |
| VideoHV 验证员（作者默认已是本地 Qwen） | **Qwen3-8B** | 零改动 |
| VideoHV 4 段摘要重生成（原 GPT-3.5-turbo） | **Qwen3-8B** | 文本→文本，属文本侧 |
| VideoAgent captioner（原 LaViLa 离线）| **Qwen3-VL-8B** | ⚠️ **看图写话必须 VLM**，纯文本 Qwen3-8B 干不了这活 |
| VideoHV caption 工具（原 GPT-4o） | **Qwen3-VL-8B** | |
| 五臂里的 D（读文字的 VLM）/ C（直接看帧）/ A′（问题条件化重生成）/ B viewer | **Qwen3-VL-8B** | |

**四个配套决定（跟名册绑死）**：

1. **Qwen3-VL-8B 用 Instruct 变体**——与现役铁律 backbone、C1、漂移探针同款；captioner 不用 Thinking 版（写 caption 不需要思维链且慢）。
2. **Qwen3-8B 的 thinking 开关待 spike 定**：它是混合思考模型（`enable_thinking` 开关，非独立 checkpoint）。格式关键步骤有 83.3% 格式失败前科 → **H2/H3 各跑 on/off 两档，按格式存活率+准确率择一，之后全程统一**。
3. ⭐ **统一 viewer 原则**：**正式五臂的 caption 全部由 Qwen3-VL-8B 重生成**（A/A′/B/C/D 共享同一个 viewer → 通道成为唯一变量；两个 host 也因此共享感知底座，§6.2 红利②不降反升）。**LaViLa/LLoVi 原资产只用于"复现原 repo 数字"的 sanity 层。两层别混。**
4. **名册外组件**：VideoAgent 检索器需同源"文本编码器+帧特征"对（EgoVLP/SigLIP/ViCLIP 任选、两侧同源，H2 第三刀）——不是 LLM，不在名册；VideoHV 的 CogAgent 检测摘要**正式臂砍掉**——⚠️ 2026-08-05 源码证实它是**死参数**（五个结构化阶段形参名皆为 `_object_detection_summaries`、无一处引用，[06 追问之四](06-videohv-workflow-source-analysis.md)），**砍 = 零损失**。

> 📌 这对名册还保护着一个形状红利：Qwen3-VL-8B 语言塔与 Qwen3-8B **KV 几何逐项相同**（36 层/4096/8 KV 头/head_dim 128，§4.1）——B 臂 adapter 的读料免 reshape。换任何一侧名册这条就没了。
> 📌 第二尺寸接收方（CausalAudit 的 4B/8B 反转约束）→ 评测阶段加 Qwen3-4B，见 §7.2；不进主名册。

### 6.2 实验可设计性对照（判据展开）

## 7. 排期与评测纪律

### 7.1 分阶段（2026-08-05 按 §2.2 首胜优先重排）

| 阶段 | 内容 | 机时 | 里程碑/判读 |
|---|---|---|---|
| **0** | **H1 资产核查 + H2 VideoAgent 本地脑（三刀）+ caption 用 Qwen3-VL-8B 重生成**（统一 viewer；⭐ **同一遍顺手 dump 逐位 top-k 分布**——T+ 臂数据与 §5.5 软蒸馏标签一次拿齐） | ~1 天 | A 臂就绪 + T+ 资产就绪 |
| **1a** ⭐ | **T+ 臂先行 = 1b 的决策门**（2026-08-05 用户裁定：adapter 缓训，先用 CIPHER 连续 token 测试）：sender greedy caption + 逐位 top-k 分布 → receiver `Σp·E` 软嵌入 → **A vs T+**（同轨迹配对，n≈500）。**兼作 B 臂 `inputs_embeds` 管道冒烟** | ~1 天工程，零训练 | **T+>A** → motivation 免训练即证 + **B 的基线升级为 T+（adapter 必须赢 T+ 才算数）**；**T+≈A** → 不判死 B（⚠️ 非必要条件：T+ 只在"说到的位置"泄露备选，**完全没说出口的内容不经过分布**——B 读的是更深处状态），但先跑 D0-a 复述探针（凭 latent 复述 caption **没有的**细节）再决定训不训 |
| **1b** ⭐⭐ | **首胜实验**：adapter v0（§5 配方，可先只跑软词瓶颈一档）+ B serving（`{caption}` 槽单点 `inputs_embeds` 注入）→ **A vs T+ vs B**（VideoAgent × 1 库，n≈500，McNemar + **零向量对照**） | ~2 天工程 + ~10 GPU·h | **B>A 显著 = 头条信号到手**；B−T+ = adapter 存在理由 |
| **2a**（若 B>A） | **加固**：C/D/A′ 臂 + CAG + 双尺寸接收方 + VideoHV 第二 host（H3 spike + H4 抽帧）+ 全格报告 + **效率账（vLLM 迁移 + prompt_embeds 吞吐验证，§7.2-6）** | 论文节奏 | 三条护栏在此补齐（§7.2） |
| **2b**（若 B≤A） | **诊断包**：D0-a 复述 → D0-b 示范 → D0-c 单调性 → D0-d 反解 → C−D headroom → 重构上界，逐级定位输在哪 | 按需 | 病因明确后决定修桥/换训练目标/止损 |
| **随时** | γ 免训练判死（1 GPU·h，可写进论文的一段） | 1 h | 可选并行 |

> ⭐ 旧排序（"判死实验全部在 adapter 之前"）的存档见 TRASH v1。**新排序接受"adapter 可能白训"的风险换最快核心信号——用户裁定（§2.2）。**

> ⭐ **同栈原则（准确率对比成立的前提，2026-08-05 追问确立）**：A vs B 的**准确率**对比两臂必须**同一推理栈**（同 kernels/dtype/sampling，否则涨跌可能是栈差不是通道差）。分工：
> - **首胜实验（准确率）**：**两臂都跑 HF**（n≈500 HF 扛得住；B 臂 reasoner 用 `generate(inputs_embeds=…)`）
> - **效率账（⚠️ 后置，用户 2026-08-05 裁定：B>A 确认后才启动）**：两臂都迁 vLLM——B 走 `--enable-prompt-embeds` + **completions 端点收 bytes 张量**（本机 vllm 0.18.0 已支持，chat 模板自己套）；**A 也走 completions 手动套模板**，对齐代码路径
> - **viewer 侧读料**：h 走 HF `output_hidden_states`；**KV 可走 LMCache 连接器（自家轮子）**
> - **adapter 训练**：必然 PyTorch/HF（vLLM 只管推理）
>
> **分界口诀（追问回填）**：**这个数字会不会和另一个数字相减？会 → 同栈（HF）；不会 → 哪个快用哪个。** 三类不受同栈约束、推荐 vLLM：①**离线资产制作**（caption/摘要重生成、抽帧——所有臂共享同一份输入，制作栈差不进臂间对比）；②**工程冒烟**（H2/H3 spike 测的就是 vLLM 路径本身）；③**效率账**（生产栈上测才有意义）。HF 侧内部也要统一：**attention 实现（flash-attn/sdpa 二选一全用）+ bf16 + greedy + 固定 seed**——同是 HF，配置不同照样有栈差。

### 7.2 评测纪律（缺一条都会被审稿打回）

1. **CAG 进主表**：`CAG = 收到本题 latent 的表现 − 收到别题 latent 的表现`；对照臂 = 零消息 / 随机消息 / shuffle / caption / C 臂上界。依据：因果审计实测总效应 −1.00pp 可拆成 −6.17 与 +5.17 两块方向相反的分量。
2. **桥替换对照**（抄 Latent Bridge）：把训好的 latent 换成**全零/随机向量**看分数变不变——最便宜的"latent 是否只是 prompt 扰动"检验。
3. **≥2 个尺寸的接收方**：因果审计的结论在 4B/8B 间会**反转**。
4. **按题型分层报**：C1-rev 与 Sterner 同向证明通道价值取决于题型（简单感知题上多绕一道会帮倒忙），只报总分会被一个 −17.6 拖垮还看不出原因。
5. **解析失败率单独报**：两个 host 的源码都有"解析失败→random 答案"兜底，不拆开会污染臂间对比。
6. **效率账对手是 SPARC**（低分辨率搜+选区高分辨率，TTFT 200×），不是"全量重编码"稻草人。**⚠️ 整条后置：B>A 确认后才做（§2.2 裁定）。**我们仅存的差别：**crop/zoom 每次重看都要重过视觉编码器，KV 复用不过**（Kamera：230ms 编码 vs ~5ms replay）——这个差必须实测。墙钟+显存+吞吐三口径。

## 8. 写论文的红线

> 这一章回答：**哪些话不能说、哪些先例必须引、哪些设计约束不能违反。** 完整论证见 [01](01-prior-art-audit.md)（审计）与 [03](03-eight-risk-papers-explained.md)（八篇危险论文逐一讲解）。

### 8.1 三句不能说的话

1. ❌ "没人做过视觉→latent→冻结纯文本 LLM" —— Frozen(2021)/BLIP-2 谱系占满，NavGPT-2 连循环都做了（四个冻结文本 LLM 互换）。**只能 claim (a)+(d)。**
2. ❌ "文字带宽不够 / latent 更保真" —— Latent Bridge 自己否掉 bandwidth story；Sterner caption 赢 4.5；LimitsOfText 证明文字丢的 88% 特征主要是表层形式；我们 C1-rev 同向。**它是待检验假设（§3 的 D0-d 就是检验它的）。** 📌 与 §2.1 放宽不冲突：放宽后的主主张是"**在盲 reasoner 人群上实测涨分**"（经验结果），仍不能写成"latent 本质上比文字保真"（机制前提）。
3. ❌ Vision Wormhole 的 off-manifold 段落当"领域认为不可能" —— 五年前就被实验解决，审稿人会读成稻草人。

### 8.2 必须正面引的先例（每个一句话，详见 03）

**CIPHER**（"传分布不传 one-hot"机制的原创，自身要求共享词表——T+ 臂必引）· **Latent Bridge**（F/T/L 三臂结构与我们同款，接收方是 VLM）· **Mem-W**（五占四，差的只有模型边界）· **NavGPT-2 + Sterner**（推翻我们两条原主张的）· **LinguDistill**（唯一逐层 KV→冻结文本 LM，但同架构、仅训练时）· **ChronoStitch**（mRoPE 重定基的模型内先例）· **SeeingEye/BeMyEyes**（P1+P3+P4 的文字通道版=我们的强基线）· **SPARC**（效率对手，ICML'26）· **MemDreamer**（纯文字图记忆打赢整段像素——我们 motivation 的最强反例，靠 C 臂的干净对照回应）。

### 8.3 六条设计硬约束（违反任何一条=已发表负结果的重演）

| # | 约束 | 出处 |
|---|---|---|
| 1 | 免训练版只当故意报告的负结果跑一次 | 4/4 论文：训过的吊打免训练 |
| 2 | **混合通道**：细文字控制通道（取帧请求+答案）+ latent 只装感知载荷；**若做双通道必须训练时同时在场** | HyLaT −6.65（文字是 semantic anchor）；Latent Bridge 双通道打架 −96% |
| 3 | 载体若改直接 KV 注入，只传浅层 | LACO 全深度最差（27.61 vs 32.65）；**仅适用于载体=KV 的路线，约束不到读料** |
| 4 | adapter 第一段用 caption 监督引导，第二段必须换任务信号 | MACF Stage1 −14.9；Sterner 只训 captioning 则 VQA 输 |
| 5 | 文字基线用 SeeingEye/SportMV 强度原样跑 | 审计约束 5 |
| 6 | 评测纪律 §7.2 全套 | 因果审计 |

**白送的评测切片**：BeMyEyes 主动丢弃"视觉信息太复杂、文字传不过去"的样本——那批被扔掉的样本就是我们最好的测试集。

**真空的三份独立证据**（写 related work 用）：39 篇视觉 KV 论文穷举全是模型内 · Beyond-Tokens survey 18 法仅 VW 碰视觉且全文字任务、"multi-round/feedback" 0 次 · C2C 把两半都写进 future work。

## 11. 术语表

| 词 | 意思 |
|---|---|
| **viewer / reasoner** | 看帧的视觉模型（Qwen3-VL-8B）/ 做决策的纯文本推理模型（Qwen3-8B-Thinking） |
| **文字边 / 切口** | host 里 caption 从 viewer 流向 reasoner 的那条边；我们手术只换这一条 |
| **五臂 A/D/C/A′/B** | 现状文字 / 换读者控制组 / 直接看图 / 先知 caption / 我们的 latent（§3.1） |
| **D0-a/b/c/d** | 四级判死探针：复述 / 示范敏感度 / 训练单调性 / 反解阶梯（§3.0） |
| **实验 γ** | 1 小时免训练判死（§3.2） |
| **伪 token** | 塞进 reasoner 输入嵌入序列的连续向量，不对应任何真实词 |
| **读料 / 载体** | adapter 从 viewer 取什么 / 以什么形式进 reasoner——两条正交轴（§5.3） |
| **软词瓶颈** | 输出头变体 B：消息=词嵌入的概率加权和 `softmax(h·Eᵀ/τ)·E`（§5.4） |
| **CAG** | content attribution gain：本题消息 − 别题消息 的表现差（§7.2） |
| **桥替换对照** | latent 换全零/随机向量看分数变不变 |
| **反旋/重旋** | 把 K 按发送方 rope_theta 转回去、再按接收方的转过来的确定性位置修正 |
| **H1–H6** | host 预检卡（§6.4） |
| **spike** | 半天级的可行性试探（此处特指 H3） |
| **P1–P5 / (a)(d)** | idea 的五个打勾性质 / 幸存的两个合取项——定义见 [03 §0.5](03-eight-risk-papers-explained.md) |
| **C1-rev** | 图像 VQA 时代的四臂对照修订版结果（[归档线](../VMAS-latent-collab/README.md)） |
| **E4(d)** | 帧数/视野混淆门槛：对照两臂的视觉吞吐必须相同 |
