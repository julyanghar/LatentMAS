# 20 · 阶段性判决书：VideoMAS 打不过单 VLM——在其上做优化暂无价值

> 2026-08-10 归档。本档是 videomas-gate 战役（门实验 1.0，双 benchmark）的独立结论存证。
> **当前暂时结论（用户裁定）：VideoMAS 上做优化没有价值。**
> 适用边界见 §四——该判决限于"视频装得进单模型上下文"的域；上下文溢出域（小时级）未判，
> agentic 单体路线（检索/记忆式）不在本判决范围内。

---

## 一、判决

在 EgoSchema 与 NExT-QA 两个 benchmark、三种 MAS 形态、六个与单 VLM 的配对判决中：
**零个显著为正、两个显著为负**。多智能体协作在此域内最好打平、典型情况倒贴。

## 二、证据链

### 自证（本项目实验，全部 500 题/格、同服配对、T=0、判据预注册）

| 对比 | 数字 | 判 |
|---|---|---|

| EgoSchema G3（辩论×2轮）− 73.4 | +0.8 p=.56 | n.s. |

| NExT-QA XG2（分工+视觉流）− 84.6 | **−4.4 CI[−7.3,−1.5] p=.005** | **★显著更差** |
| NExT-QA XG3（辩论）− 84.6 | −1.8 p=.09 | n.s.（边缘负） |

附带的显著正结果（不改变判决但指路）：**信道介质效应** XG2−XG1=+2.4（b=17 c=5, p=.017★）——
agent 间传关键帧显著优于只传文字。

### 他证（三篇独立文献，方法互异、结论同向）

1. **ViF**（ICLR 2026）：朴素文本消息 VLM-MAS 随轮数退化，20 轮低于单 agent（Fig.7）；机制=下游
   视觉注意力衰减 −62%，"幻觉雪球"；
2. **MACF**（arXiv 2605.00444, Table 1）：文字通信 MapReduce 多 agent 在 Video-MME 46.7，
   比单模型 Qwen3-VL-8B 的 55.9 **低 9.2**；免训练 LatentMAS 版 55.7≈单模型零增益；
3. **LVAgent**（ICCV 2025 消融）：裸三模型集成 ≈ 最强单成员——多智能体本身贡献 ≈0，
   增益全部来自检索与淘汰机制。

## 三、机制分析（为什么打不过，五条，各有实测）

1. **信道转写损失**：侦察报告 ~25:1 压缩，继承 caption 丢失（像素>caption 双 bench：+8.2★/+3.2）；
   因果证据=补关键帧显著挽回 +2.4★；
2. **时序邻接被分段切断**：NExT-QA "接下来发生什么"(TN)型损失率 21.1%、净−15=头号灾区；
   视觉流救回题中 8/17 恰为 TN（帧号缝回顺序）；
3. **上下文未饱和时分工无上行空间**：视频装进单模型上下文时，单模型=完整视觉访问+全局注意力，
   MAS 上限=打平（信道无损），常态=倒贴（信道有损）；
4. **幻觉雪球**（ViF）：上游文字报告的视觉误读被下游当权威放大；
5. **同输入辩论不产生新信息**：N 倍算力买自洽；保住全员视觉访问的辩论形态（G3）损失最小——反证
   视觉访问才是主变量。

**统一律（13 格单一解释）：性能 ∝ 接收方可直接访问的视觉信息量。**

## 四、判决边界与后续方向（不在本判决内）

- **上下文溢出域未判**：视频长到单模型装不下时（>~6-10min@本项目预算），分工才有理论上行空间
  ——HourVideo 战役（hourvideo-gate）专门检验，进行中；
- **agentic 单体路线不受本判决约束**：检索/记忆式单 agent 工作流（DVD/ViSAGE 族）在长视频文献中
  稳定超单 VLM，是当前主攻方向（自证实验筹备中）；
- **信道介质科学保留并升级**："看→想"接口的介质效应（文字<关键帧,+2.4★）与 MAS 存亡无关，
  将在过门的 agentic 宿主内部继续（等预算三介质消融+替换因果审计）。
