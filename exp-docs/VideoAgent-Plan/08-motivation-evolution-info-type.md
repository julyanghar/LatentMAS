## 一、Motivation 的四段演化

**v1（立项）**："文字有损，latent/概率通信更强，尤其多模态"——把 viewer→reasoner 的文字通道换成连续载体应当普遍涨分。

**v2（先例审计后放宽，2026-08-05）**：普遍性主张被文献打薄（Sterner：caption 赢 latent 4.5 分；Latent Bridge 作者自己拒绝"文字带宽不够"叙事），退为**存在性主张**——只要存在一条文字边换 latent 能涨分即证明价值。

**v3（探针后，2026-08-07）**：升级为条件化假设——**最优载体由信息类型决定**（感知→大带宽载体；推理→连续载体可能有红利，CIPHER 的正结果全在此类；窄而任务相关的通道文字够用）。

**v4（P2 全阴后，2026-08-08，现行）**：条件化假设**不获支持**——推理行三种连续载体（概率/latent/CIPHER 软自回归）全阴，感知行概率终审也阴。幸存的立论只剩一条，但它是显著且干净的：**感知信息在"画面→文字"转写那一刻不可逆丢失（C−D=+6.0, p=.008），这个损失读者侧无解（换 VL/32B 均不救），唯一出路是让接收方绕过文字直接吃视觉表征**。项目主命题从"载体升级"收缩为"感知瓶颈钉死 + 跨模型 adapter"；当前动作=30B 最强读者下重钉像素红利（§八）。

## 二、实验对立论的七次冲击（结论台账）

| # | 发现 | 对立论的作用 |
|---|---|---|
| 1 | **工具通道全饱和**：T+/像素/换读者/先知四路增强全部无效（150 token 按需通道） | 划定文字够用的边界——"窄+任务相关"时别折腾 |
| 2 | **地图通道文字有损实锤**：C−D=+6.0（p=0.008），像素臂 65.6 全场唯一超原系统 | v1 的核心前提在大带宽感知通道上**成立**——但赢家是像素不是概率 |
| 3 | **头条 +4.8 被探针解构**：~4.2 是"软载体对分词分歧免疫"；零分歧下概率平手 | "概率有信息红利"在感知转述上不成立；换得一个机制发现 |
| 4 | **8B 冤案部分平反**：8 分"读者差"= 分词分歧 4.2（显著，结案）+ **~3.8 悬案**——仅在"VL 读自家书"出现（读者@我们的书 +3.8 p=.10、书@VL +4.0 p=.088，双视角边缘同向；中立书上 55.8 vs 55.6 严格相等 46:47） | 方法学：拼接注入类工作普遍暗背 ~4 分税；"文体亲和 vs 读者能力"由 2×2 区分（能力应两书都赢，实际只赢自家书）——**未结案，30B 战役 D₃₀（VL-30B 读自家新书）将再给一次证据** |
| 5 | **跨 GPU 管道级非决定性**：同臂跨卡 28% 翻题 | 方法学：跨卡对比的隐形噪声地板 ±2.2 |
| 6 | **P2 全阴（2026-08-08）**：CP −1.2 / CL +0.4 / CIPHER−CT′ +0.2 / P2-1 +1.6，全 n.s.；CIPHER 软自回归单跳 587/587 顶满不自停（轨迹崩塌）；latent 对齐后完全可读但高扰动净零（翻题 140） | **v3 条件化假设证伪**；概率/裸 latent 通信在本 host 定论"仅剩分歧免疫价值"；CIPHER 效应不迁移到单跳线索通信 |

## 三、"信息类型 × 载体"矩阵（终版，两层口径勿混用）

**隔离效应层**（同对同题同书同骨架，判决级）：

| 相对同基文字(55.8) | top-64 概率 | latent | 像素 |
|---|---|---|---|
| 感知（地图） | +1.6 n.s. | 未测（同模型喂读无增量；异构需训练=B 臂方向） | **+6.0 显著** |
| 推理（线索） | −1.2 n.s. | +0.4 n.s.（LatentMAS 对齐） | —（CIPHER vs 非引导对照 +0.2 n.s.） |

**全景最好成绩层**（不控变量，跨战役 ±2.2 地板，参考用）：文字 60.8（工具战役族）· 像素 65.6 · 概率 57.4 · latent 56.2。
细节与口径辨析见 [10 全臂图鉴](10-all-arms-atlas-explained.md)。桥接副产品：非引导线索比引导 JSON 线索弱 4.6 分（p=.064）——结构化引导有内容价值。

## 四、与文献的调和（论文 Related Work 的骨架）

- **CIPHER**（ICLR'24）：概率通信赢文字的场景是 LLM 辩论=多跳立场聚合。**P2 已实测其机制不迁移到单跳线索通信**：软自回归轨迹快速崩塌（48 步顶满、影子复读），效果与同等弱的非引导文字线索打平——调和结论从"互不矛盾"升级为"**边界实测**：CIPHER 效应需要多跳聚合结构，单跳转述场景不适用"。
- **Latent Bridge**（2606.24470）：作者拒绝"文字带宽不够"叙事——与我们互补且被我们的全阴加固：**带宽瓶颈不由载体决定，由通道与信息来源决定**（同一文字载体：工具通道饱和、地图通道有损；同一地图通道：换载体全阴、绕过转写 +6）。
- **Sterner**：caption 赢 latent（感知特征、接收方冻结）——落在我们矩阵"感知×latent 免训练"的坏格里；与 B 臂（训练 adapter）不冲突，且我们的 CL 结果补了推理侧版本：同模型 latent 可读但零增益。

## 五、创新点清单（P2 后重排）

1. **分词分歧免疫**（实测，全新）：离散 one-hot 载体过拼接边界交 ~4.2 分税、连续载体免税——对一切拼接注入类方法是普适警钟。
2. **感知通道像素泄漏的 agentic 量化**（实测）：同读者同帧集像素>文字 6.0 分，带正负双对照（工具饱和=负对照）；30B 复核进行中（§八）——若存活即为 adapter 的 6 分靶子。
3. **"信息类型×载体"矩阵的全阴判决**（实测，负结果主命题候选）：两类信息 × 三种连续载体在同一受控系统内全部无红利——统一解释 CIPHER/Latent Bridge/Sterner 表面矛盾的同时，给"latent 通信热"提供第一份系统性受控阴性证据（含 CIPHER 单跳边界实测）。
4. **方法学副产品包**：跨 GPU 管道级非决定性（28% 翻题）；输出帽暴露不对称审计法（最坏界记账）；退化复读处置协议；同对配对纪律；零分歧对齐器。

## 六、诚实边界（写论文时不许越过）

- 8B 时代**没有任何软/概率配置在系统层面打赢原始 LaViLa 基线**（60.4）；唯一赢家是像素臂 C（65.6）；
- "文体亲和"（VL 偏爱自家 caption +4.0）**p=.088 未达显著**——只能当疑似效应/保险动机，不得当结论引用；
- §六旧条款"概率红利若 P2 全阴则定论"**已触发**：概率通信在本 host = 仅剩分歧免疫价值；B 臂转纯感知侧（预注册分支，非事后决定）；
- 感知/推理二分作为**解释框架**保留，作为**载体选择依据**已被数据否决；
- 像素红利目前只在 8B-VL 读者上立案；30B 复核（§八）出结果前，"最强读者下仍在"不得预支；
- 跨战役水位差（如 tool 60.2 vs 探针 55.8）含**摘要换源**（GPT-3.5→8B 重生成）这一未定量因子——跨战役数字并列展示时必须脚注，禁止当同口径比。
