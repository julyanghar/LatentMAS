# 10 · 全臂图鉴——每条臂到底改了哪里（全自产口径版）

> 2026-08-08 按全自产口径重写（原则见 [12-self-produced-caliber-replan](12-self-produced-caliber-replan.md)）：**只收录地图与摘要均为系统在役模型自产的实验**。剔除的现成材料实验（工具战役、探针 LaViLa 格）见文末"剔除说明"，完整旧版在 git 历史（commit f10348a 前）。
> 读法：先读"约定"和"不变的底座"，各战役独立成节可跳读；P2 细节另见 [09-p2-cards-design-explained](09-p2-cards-design-explained.md)。

**TL;DR**：所有臂遵守同一条设计法则——**整个系统只动一处，其余逐字节不变**；动的那一处永远围绕"验证员"：换它收到的**某样东西的形态**，或换它**本人**。臂间两两相减，每个减法隔离一个变量。全自产口径下的两大判决：**像素>文字 +6.0（显著）**；**概率/latent/CIPHER 三种连续载体全阴**。

## 约定（本文所有抽象词先落地）

| 词 | 指什么（含具体例子） |
|---|---|
| **自产口径** | 地图与摘要均由战役在役模型现产（书=在役 VL 自写；摘要=在役文本模型×自产书）——latent collaboration 要求中间表征是"活的"、可被 latent 通道替换（doc12） |
| **臂** | 一次 500 题完整运行，系统里只改一处 |
| **验证员** | 四角色中唯一消费视频证据的角色（8B/VL/30B 系）——所有手术都在它身上或它的输入上 |
| **地图** | 验证员开场必读的 180 条逐帧 caption（~1.5-2.5k token）——验证层的证据册 |
| **摘要** | 4 段叙事+总纲（dpcknn 切 4 clip→LLM 逐段叙事）；出题人/判官/选答人共用的案情概述，验证员**不读**；early-exit 题由它独裁。自产版本：8B×自产书（8B 时代）/ 摘要₂=30B×自产新书（30B 主线）。root 总纲与 object_detection 摘要=管线死重不消费 |
| **书** | 自产地图：Qwen3-VL-8B 逐帧自写单句版（"c holds the embroidery hoop"）；30B 时代由 VL-30B 重写（S2） |
| **摄影师** | 执行工具调用的在役 VL：验证员点名 ≤5 帧后现场看图写描述（全实验恒自产；与 D/C 臂验证员同模型不同角色） |
| **递送** | 文字变模型输入的方式：chat（服务端整段切）/ one-hot embeds（整切后查表发向量，已证与 chat 逐题等价）/ **拼接 embeds**（生成流旧块焊接——带分词分歧） |
| **分词分歧** | 分段切再拼 vs 整段一次切的 id 差异（例：`".\n"`=整切 `[624]`、分切 `[13,198]`）；实测税=4.2 分 |
| **Σp·E（软嵌入）** | 一个位置放"top-64 候选词向量按概率加权的和"，而非某个词的向量 |
| **同对配对** | 被比较两臂跑同一组 GPU（跨组 28% 翻题非决定性，实测）；判决一律同对减法 |
| **b / c / p** | 配对翻题统计：b=仅 X 对的题数，c=仅 Y 对的题数。p=McNemar 精确检验——**读法**：若两臂真实相同（翻题=公平硬币），掷出这份不平衡或更偏的概率；p 大=噪声就能造出来，不立案；p≠"效应为零的概率"，n.s.≠证明为零。95%CI 夹的是**真实平均差**（重做百遍实验约 95 个区间罩住真值），不是逐题差值的分布范围；CI 跨零⟺p>.05 |
| **span** | 某段载荷文字在整段分词后的骨架里占据的连续 token 位置区间 [起,止)。例：线索 "Check whether…" 占 62 位即"线索 span"；手术只发生在 span 内的对齐位（边界融合位回退硬），区间外零字节不动 |

## 不变的底座（战役内逐字节共享）

```
出题人 → 判官 → 验证员(★手术位) → 选答人     （文本角色，随战役代际 8B→30B）
                    ↑
              工具摄影师(在役 VL,现场写描述)
同一份 500 题单 · greedy(T=0) seed42 · 逐题落盘 · 判据先冻结后跑
```

四角色里**只有验证员被动过**；摘要、题目、选项、模板在同一战役内逐字节相同。

## 进阶追问区（可跳过）

**Q1：为什么 map-A 陪绑拼接？** 为让 T+−A 只差软硬一个变量（概率账本按生成流切法记账）。探针证明这枷锁值 4.2 分——P2 零分歧铁律即此教训。
**Q2：隔离矩阵的格子带分词分歧吗？** 不带。基座 P-a=chat 整切（无拼接动作），P-b 与其 b=0 c=0；P2 注入全走零分歧对齐器（边界位回退硬、逐调用计数）。唯一受害者 map-A 正因带税被踢出基座。
**Q3：65.6 那条臂各角色都是 VL 吗？** 不是——只有验证员换 VL（看 180 帧），其余角色文本模型，摄影师照旧回文字。含义：像素红利从**单一角色的单一输入通道**进来，下游传的仍是文字——adapter 靶子因此聚焦：只需让文本验证员直接吃视觉表征替代那 180 张图。
**Q4：CL 的 latent 怎么过 LatentMAS？异构不是不能用吗？** 闭式对齐只适用同模型。CL 选了管线唯一同模型信道：线索=判官(8B)→验证员(同一份 8B 权重)。感知×latent 未测：地图信息源头是 VL，需 VL→文本**异构桥=要训练**（即 adapter 方向）；免训练"喂读文字取状态"结构上无增量。
**Q5：P2-1 的 +1.6 算收益吗？** 不算。①p=.38：无效应时纯翻题噪声掷出该差距的概率 38%，CI [−1.5,+4.7] 跨零；②同一问题的独立复测（工具 T+，高基座同构手术）方向相反（−2.4 n.s.）——两次围零跳动=真效应≈0 的典型形态；③α=.05 预注册，事后把 n.s. 当小收益讲=放宽判据。
**Q6：读者升级能救文字吗？** 不能——自产书上 8B 55.8 / 32B 58.6 / VL 59.6 挤在同一 ~59 平台（P-7 vs map-D −1.0 p=.72），都离像素 65.6 差 6 分；30B 战役 A₃₀=57.6 又落同一平台。瓶颈在载体不在读者。

## 附：p 值与置信区间零基础讲解（用 P2-1 真实数字，2026-08-09 答疑回填）

**第 1 步：配对四格表。** 两臂逐题配对后每道题只有四种命运（P2-1 vs P-a，500 题）：

| | P-a 对 | P-a 错 |
|---|---|---|
| P2-1 对 | 251（都对） | **b=36**（只有 P2-1 对，"翻上"） |
| P2-1 错 | **c=28**（只有 P-a 对，"翻下"） | 185（都错） |

436 道"都对/都错"的题两臂表现一样，对"谁强"零信息，相减抵消——证据全在 64 道翻题里。自检不变量：b−c 必等于两臂对题数之差（287−279=8=36−28），对不上=账错。

**第 2 步：造假想世界（无罪推定）。** 假设两臂真实水平完全相同——那每道翻题翻向哪边就没有理由偏心，等于掷一枚全新的公平硬币。64 道翻题=掷 64 枚硬币。注意：硬币是**全新的 50/50**，不是从 36:28 里有放回抽样（那是 bootstrap，回答的是 CI 那类"晃动多大"的问题，方向相反）。

**第 3 步：公平≠对半。** 掷 64 枚公平硬币，正好 32:32 的概率只有约 10%；结果天然散成一条以 32 为中心的钟形——36:28 这种"看起来偏"的结果在纯运气世界里稀松平常。

**第 4 步：p=尾巴面积。** 问：运气世界掷出"36:28 或更偏"的概率多大？实操就是三行算术（不跑任何实验）：

```
p = Σ C(64,k)/2^64,  对所有 k>=36 或 k<=28 求和 = 0.3817
```

笨办法版（等价）：真的用随机数掷 64 次×10 万场，数有几场偏度达标，命中比例≈同一个数。McNemar"精确检验"的精确=用公式逐种情形数清楚。p=0.38 意思是：纯运气三场里就有一场能复刻我们的证据——辩方（运气）辩护成立率太高，不立案。判案门槛 α=0.05 开跑前冻结。

**第 5 步：95% CI 手算。** 把每道题记一个数 D：翻上=+1（36 题），翻下=−1（28 题），其余=0（436 题）。
- 平均 = (36−28)/500 = +1.6 个百分点（点估计）；
- 单题方差 = (36+28)/500 − 0.016² ≈ 0.128；500 题均值的标准误 SE = sqrt(0.128/500) = 1.60 个百分点；
- CI = +1.6 ± 1.96×1.60 = [−1.5, +4.7]。

口诀：**均值定中心，标准差除以根号 n 定步长，1.96 步定夹宽**（CI = 均值 ± 1.96×标准差/√n）。除 √n 是关键——标准差量的是单题晃动，CI 夹的是 500 题平均值的真值，平均会把晃动压小 √n 倍；漏掉它夹子会宽 22 倍。1.96=正态曲线罩住 95% 面积的查表步数（99% 换 2.58），前提 n 够大（中心极限定理，500 绰绰有余）。
读法：夹的是**真实平均差**这一个数（重做百遍实验约 95 个夹子罩住真值），不是逐题差值的范围。夹子跨零 ⟺ p>0.05——同一条钟形曲线的两种量法（p 量尾巴面积，CI 量夹子宽度）。

**三条不许误读**：①p 不是"无效应的概率"（主语是证据不是效应）；②n.s.≠证明为零（可能效应太小抓不住，只写"分不清"）；③门槛 0.05 事先冻结，不许看到 p=0.06 现场放宽。
