# 10 · 全臂图鉴——每条臂到底改了哪里（零基础版）

> 缘起：三个战役（tool-channel / map-channel / 入口①探针）+ 进行中的 P2 共约 20 次 500 题运行。本文是**逐臂对照手册**：每条臂的基准是谁、精确改了哪里、判决数字是多少。
> 读法：先读"约定"和"不变的底座"，之后各战役独立成节可跳读；P2 细节另见 [09-p2-cards-design-explained](09-p2-cards-design-explained.md)。

**TL;DR**：所有臂都遵守同一条设计法则——**整个系统只动一处，其余逐字节不变**；动的那一处永远围绕"验证员"：要么换验证员收到的**某样东西的形态**，要么换验证员**本人**。臂间两两相减，每个减法隔离一个变量。

---

## 约定（本文所有抽象词先落地）

| 词 | 指什么（含具体例子） |
|---|---|
| **臂** | 一次 500 题完整运行，系统里只改一处。例：验证员读文字=一条臂，读软嵌入=另一条臂 |
| **验证员** | VideoHV 四角色中唯一消费视频证据的角色（8B 或换成 VL）——所有手术都在它身上或它的输入上 |
| **地图** | 验证员开场必读的 180 条逐帧 caption（~1.5-2.5k token）——验证层的证据册 |
| **摘要** | 4 段叙事+1 总纲（dpcknn 切 4 clip→LLM 逐段叙事→总纲）；出题人/判官/选答人共用的案情概述，验证员**不读**；early-exit 题由它独自定答案。三代：原版 GPT-3.5 读 LaViLa（随仓分发）→ M-H2b 8B 读我们的书 → S1 30B 读 LaViLa。代码中 object_detection 摘要带下划线参数=死重不用 |
| **摄影师** | 执行工具调用的 Qwen3-VL：验证员点名 ≤5 帧后，它现场看真实图片写一段描述返回（与 D/C 臂的 VL 验证员是同一模型演不同角色）。地图=离线印好的书，摄影师=随叫随到的现场速写员 |
| **工具返回** | 验证员喊"给我看 N-M 帧"后摄影师现场写的描述（~100-200 token）；C 臂里摄影师下岗、原图直接进对话 |
| **LaViLa 书 / 我们的书** | 地图的两种来源：LaViLa 动作电报体（"#C C inserts needle"，族谱=Meta LaViLa 模型→LLoVi 论文批量跑好公开→上游仓库打包→我们只读文件，LaViLa 从未在本机跑过）/ 我们用 Qwen3-VL 逐帧自写的单句版（"c holds the embroidery hoop"；S2 有 VL-30B 重写版） |
| **递送** | 同一段文字变成模型输入的方式：chat 文字（服务端整段切）/ one-hot embeds（客户端查表发向量，已证与 chat 逐轨迹等价）/ **拼接 embeds**（沿用生成流旧块焊接——带分词分歧） |
| **分词分歧** | 分段切再拼 vs 整段一次切的 token id 差异（例：`".\n"`=整切 1 块 `[624]`、分切 2 块 `[13,198]`）；实测税=4.2 分 |
| **Σp·E（软嵌入）** | 一个位置不放"某个词的向量"，放"top-64 候选词向量按概率加权的和" |
| **同对配对** | 被比较的两臂跑在同一组 GPU 上（跨组有 28% 翻题的非决定性，实测） |
| **b / c / p** | 逐题配对统计：b=只有 X 臂对的题数，c=只有 Y 臂对的题数，p=McNemar 精确检验 |

## 不变的底座（所有臂逐字节共享）

```
出题人(8B) → 判官(8B) → 验证员(★手术位) → 选答人(8B)
                              ↑
                    工具摄影师(Qwen3-VL,现场写描述)
同一份 500 题单 · greedy(T=0) seed42 · 逐题落盘 · 判据先冻结后跑
```

四个角色里**只有验证员被动过**；摘要、题目、选项、指令模板在**同一战役内**逐字节相同（P2 的线索臂改的也是"验证员收到的线索"，判官本身不动）。**跨战役注意**：工具战役用原版 GPT-3.5 摘要，地图/探针/P2 用 8B 重生成摘要（git 525b112 vs 0fdd6f6 铁证）——战役内恒量不进判决，跨战役水位比较时是隐藏因子之一（见 Q5）。

## 战役一：tool-channel（手术位=工具返回；全跑 pair-A；地图=LaViLa 原样文字；强制每题≥1 次工具调用）

**基准 A（60.2 分）**：验证员=8B。工具返回以摄影师**生成流的原始 token** 焊进对话（为配对陪绑，每题仅 2-6 处分词分歧，量级可忽略）。地图作为 W_prompt 字符串的一部分整段自然切（零分歧）。

| 臂 | 相比 A 改了哪里（仅此一处） | 分数 | 判决 |
|---|---|---|---|
| **T-A0**（60.4） | 取消强制调用（tool_choice=auto，自然调用率 86.4%） | 60.4 | 强制协议无影响 |
| **T+**（57.8） | 工具返回的每个 token 位置 → Σp·E（同一次生成的 top-64；骨架与 A 逐位相同 473/473 实证） | 57.8 | −2.4, p=.16——概率无益 |
| **D**（60.8） | 验证员本人 8B→**Qwen3-VL**（读同样文字；线索逐字相等 474/474 实证） | 60.8 | A−D=−0.6——读者等价 |
| **C**（59.0） | 验证员=VL 且工具**返回原图**（点名的 ≤5 帧图片直接进对话，不写字；与 D 首次点名帧集相同 474/474） | 59.0 | C−D=−1.8——像素无漏可捡 |
| **A′**（60.6） | 摄影师写描述前**先看到题目与选项**（prompt 加一段；验证员首次点名与 A 相同 473/473=零实现泄漏） | 60.6 | +0.4——先知无用 |

**战役判决：通道饱和**——四种增强全部无效，~150 token 的按需描述已装下全部有用信息。

## 战役二：map-channel（手术位=地图；B/C 两片各 250 题分跑 pair-B/pair-C；地图=我们的书；工具自然调用、返回文字）

**基准 A（51.6 分）**：验证员=8B。地图以**拼接 embeds** 递送（逐帧"frame N: "前缀 ids + 摄影师生成流 caption ids + 换行 ids 焊接——~360 处分词分歧，为 T+ 配对陪绑；后被探针定罪 −4.2 分）。

| 臂 | 相比 A 改了哪里 | 分数 | 判决 |
|---|---|---|---|
| **T+**（56.4） | 地图 caption 内容位置 → Σp·E（离线 npz 的 top-64；"frame N:"结构 token 保持硬；每次调用全量注入,逐调用核验） | 56.4 | +4.8, p=.013——后被拆解：≈4.2 来自"软向量不怕分词分歧" |
| **D**（59.6） | 验证员 8B→VL，地图为**自然行文本**经 chat | 59.6 | A−D=−8.0——后拆解为分歧 4.2+文体亲和 |
| **C**（65.6） | 验证员=VL，地图段换**同 180 帧原图**（384×288，帧号标签保留） | **65.6** | C−D=+6.0, p=.008——**文字有损实锤，全场最高** |
| **A′**（57.2） | 地图换**先知版资产**（每帧 caption 生成时带题目与选项；摘要仍普通版，文件逐字节锁定） | 57.2 | +5.6, p=.013——先知在大通道有用 |

## 战役三：入口①探针（全部是"A 臂语义"的变体——没有软/像素，专拆 8 分亏空；同对分片同战役二）

每格只改 {书 × 递送 × 排版 × 读者} 中的一维：

| 格 | 书 | 递送/排版 | 读者 | 分数 | 隔离出的因子 |
|---|---|---|---|---|---|
| **P-a** | 我们的 | 行文本 · chat | 8B | 55.8 | vs map-A：装订+通路总代价 +4.2 |
| **P-b** | 我们的 | 行文本 · **整切后 one-hot embeds** | 8B | 55.8 | vs P-a：**b=0 c=0**（通路零差）；vs map-A：**纯分词分歧 +4.2, p=.046** |
| **P-c** | **LaViLa** | 行文本 · chat | 8B | 55.8 | vs P-a：书@8B **=0.0**（47:47 完美对称） |
| **P-d** | LaViLa | 行文本 · chat | **VL** | 55.6 | vs map-D：书@VL **−4.0（p=.088 边缘，未达显著）**——疑似偏爱自家方言 |
| **P-f** | LaViLa | **字典打印体** · chat | 8B | 56.8 | vs P-c：排版 +1.0 n.s. |
| **P-g** | 我们的 | 字典打印体 · chat | 8B | 54.4 | vs P-a：排版 −1.4 n.s.（两格反号=噪声） |
| **P-7** | 我们的 | 行文本 · chat | **32B**(TP2) | 58.6 | vs P-a +2.8 n.s.；vs VL −1.0——规模不解决问题 |

**战役判决**：8 分亏空 = 分词分歧 4.2（唯一显著元凶）+ 文体亲和 ~4（仅 VL）+ 噪声；书、排版、递送通路全部无罪。

## 战役四：P2（已收官 2026-08-08；手术位=按信息类型选）

| 臂 | 相比基准改了哪里 | 分数 | 判决 |
|---|---|---|---|
| **P2-1**（基准=P-a） | 地图用**零分歧对齐**贴软：整段自然切骨架上，账本能对上的 ~74% 位置（全部实义词）放 Σp·E，边界标点位保持硬（每调用 ~1153 个软位置） | 57.4 | +1.6, p=.38——感知概率无红利**终审坐实** |
| CP（基准=CT=P-b） | 验证员收到的**线索** span → Σp·E（判官同次引导生成顺手记账；首轮线索同祖 453/453） | 54.6 | −1.2, p=.54——推理概率无红利 |
| CL（基准=CT=P-b） | 线索 span → 判官末层隐状态（HF 喂读 → LatentMAS 闭式 M+范数匹配注入） | 56.2 | +0.4, p=.93——**高扰动净零**（翻题 140 vs CP 的 68），parse 零崩坏=对齐后完全可读 |
| CT′（CIPHER 的对照） | 线索换成**同判官 prompt 非引导续写**的另一句话（落子生成，one-hot 递送） | 51.2 | 桥接 CT′−CT=−4.6, p=.064——非引导线索先天弱 |
| **CIPHER**（基准=CT′） | 同一非引导 prompt，但生成**不落子**：每步 Σp·E 喂回（软自回归），e_t 最近邻=EOS 即停 | 51.4 | +0.2, p=1.0——不落子零效应；**587/587 调用 48 步顶满不自停**，影子快速复读崩塌 |
| SP/SL/ST′ | 摘要三臂 | — | 条件卡未复活（线索格全阴） |

**战役判决**：四主对比全阴 →"信息类型决定最优载体"假设不获支持；概率/裸 latent 通信在本 host 全面无红利；唯一显著红利仍是感知行的像素。

### P2 收官矩阵（两层口径，勿混用）

**第一层：隔离效应矩阵**——答"**换载体本身值几分**"。每格 = 同对同题同书同骨架、只换载体的配对减法（判决级证据）：

| 相对同基文字 | top-64 概率 | latent | 像素 |
|---|---|---|---|
| 感知（地图，基=55.8） | +1.6 n.s. | 未测（见 Q6：同模型喂读无增量、异构需训练=B臂方向） | **+6.0 显著**（C−D，同读者） |
| 推理（线索，基=55.8） | −1.2 n.s. | +0.4 n.s. | — |

**第二层：各载体全景最好成绩**——答"**该载体最好跑到过多少**"（不控制变量，跨战役/跨对带 ±2.2 噪声地板 + 协议差，只作参考不作判决）：

| 载体 | 全景最好 | 出处 |
|---|---|---|
| 文字 | **60.8**（60.2–60.8 一族） | 工具战役 D/T-A0/A′/A：LaViLa 书×8B 或 VL，pair-A |
| 像素 | **65.6**（全场最高） | 地图战役 C：VL 看 180 帧原图 |
| top-64 概率 | 57.4 | P2-1 零分歧软地图 |
| latent | 56.2 | CL（LatentMAS 对齐线索） |

为什么第一层的"文字"只有 55.8 而第二层有 60.8：55.8 是**我们的书×8B×地图通道**这一控制基座的分数——矩阵要隔离"载体"一个变量，所有格子必须钉在同一基座上；60.2–60.8 属于**工具通道×LaViLa 书×pair-A** 的另一套协议（跨战役差经探针拆解 = 拼接税 + 噪声/协议杂项，见 Q3）。把 60.8 填进矩阵会把"通道/书/对"的差混进"载体"效应——那才是不严谨。

## 进阶追问区（可跳过）

**Q1：为什么两个战役的 A 臂都"陪绑"了拼接？** 为让 T+−A 只差软硬一个变量（T+ 的概率账本按生成流切法记账，当时只能拼接）。探针证明这枷锁值 4.2 分，且方向本可反转（让 T+ 迁就自然骨架）——P2 的零分歧铁律即此教训。
**Q2：为什么工具战役强制调用、地图战役不强制？** 工具通道不强制则 14% 的题不经过被测通道（功效流失）；地图题题必读，无此问题。
**Q3：分数能跨战役直接比吗？** 同战役内的减法全部同对同题（可比）；跨战役比较（如 tool-A 60.2 vs map-A 51.6）曾产出"8.8 分之谜"，探针已把它拆平——跨对部分带 ±2.2 噪声地板，判决一律以同对减法为准。
**Q6：CL 的 latent 怎么过的 LatentMAS？我们不是异构模型吗？感知×latent 为什么没测？** LatentMAS 闭式对齐只适用同模型（M 由同一模型的 Wₒ/W_in 构成）。CL 恰好选了管线唯一的**同模型信道**：线索=判官(8B)→验证员(同一份 8B 权重)——HF 喂读判官 prompt+定稿 ids，取线索位末层 h，过 M+范数匹配后顶替验证员输入位。感知×latent 没测（也从未立卡，早前"条件卡"标注有误）：地图信息源头是 VL，测"发送方状态"需 VL→8B **异构桥=要训练**（即 B 臂二期方向）；免训练的"8B 喂读地图文字取状态"结构上无增量（读者状态信息上限=文字本身），回答不了发送方假设。
**Q4：P-7(32B) 58.6 没超过 map-D(VL) 59.6，说明 VL 更适合这个场景？** 不是。①差 −1.0、p=.72=平手，准确说法是"4 倍参数只追平 VL"。②"VL 天生适合"有现成检验：若成立，VL 读任何书都该赢，但 P-d（VL×LaViLa 书）55.6 vs P-c（8B×同书）55.8 优势归零——VL 只在读**自己写的**书时占优（+4.0，p=.088 未达显著），疑似文体亲和而非能力红利。③规模路线(32B 58.6)和文体路线(VL 59.6)殊途同归 ~59 平台，都离像素 65.6 差 6 分：瓶颈在文字载体，不在读者——这正是"32B×软"条件卡降优先级的依据。
**Q8：哪些实验用现成 caption、哪些用自产？** 工具返回全实验恒为自产（摄影师现场写）。地图：工具战役全臂+探针 P-c/P-d/P-f+30B A₃₀ 用 **LaViLa 现成**；地图战役（除 C）+探针其余格+P2 全部用 **VL-8B 自产书**；30B D₃₀ 用 VL-30B 自产新书；两个 C 臂用原图。摘要原料三代：GPT-3.5×LaViLa（工具战役）→ 8B×自产书（地图/探针/P2）→ 30B×LaViLa（30B 三格，回原版口径）。审计结论：**判决级减法全部来源同侧或来源即被测变量**；混来源的只有跨战役水位比较（书=0 已证、摘要两代作者+原料双换——只可脚注禁作判决）。
**Q7：65.6 那条臂（map-C）各角色都是 VL 吗？** 不是——只有验证员换成 VL（读 180 帧原图），出题人/判官/选答人仍是 8B 文本模型，摄影师照旧 VL 回文字。这是 C−D 归因的前提（唯一差别=同一读者读图/读字）。含义：65.6 是"文字系统里只给验证员一个角色开眼"的分数——像素红利从单一角色的单一输入通道进来，消化后往下游传的仍是文字。B 臂 adapter 的靶子因此非常聚焦：只需让文本验证员直接吃视觉表征替代那 180 张图，管线其余不动。
**Q5：隔离效应矩阵的格子是不是都带分词分歧、所以普遍分低（55.8 vs 全景 60.8）？** 不是。①矩阵全部格子零分歧构造：基座 P-a=chat 整段自然切（无拼接动作），P-b 与其 b=0 c=0；P2 软/latent 注入全走零分歧对齐器（对得上才贴软、边界位回退硬、逐调用计数落盘）。分词分歧唯一受害者是 map-A(51.6)，正因带税被踢出基座。②55.8 vs 60.8 两边都是自然整切文字，差的全账（2026-08-08 结）：排版/书交互 ~1.0（书@lines=0.0 铁证 47:47；书@dict=+2.4 p=.28 偏现成书的苗头——电报体更抗 dict 格式噪声，同一 2×2 两切法，只计一次）+ 跨对 2.2（同码同摘要只换卡实测）+ ≤1.2 的"摘要原料/作者双换源(GPT-3.5×LaViLa→8B×自产书，绑定换的分不开，未单测)+递送(0)+强制(0)+半跨对"。全部不进判决。③基座低不制造伪阴性的硬反证：工具战役 T+ 在 **60.2 高基座**上测同一"概率 vs 文字"（骨架 473/473 逐位同）也是 −2.4 n.s.——高低两个基座独立同向全阴。唯一残留口径风险=载体×系统强度交互（概率只在更强系统才有用），现有证据（高基座 T+ 阴性、32B 读者 n.s.）均不支持。
