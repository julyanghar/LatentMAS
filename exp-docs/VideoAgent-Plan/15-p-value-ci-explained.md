# 15 · p 值与置信区间零基础讲解（配对实验版）

> 从 doc10 附录独立成档（2026-08-10）。全部数字来自真实实验（P2-1 vs P-a，500 题），每个数都可复算。
> 读法：按节顺读即是概念梯子；赶时间读"一句话总纲"+"三条不许误读"。

**一句话总纲**：把每道题的胜负记成一个随机变量 D（+1/0/−1），p 和 CI 是对"D 的真实均值 E[D]"的两种审讯——p 问"E[D]=0 与数据相容吗"，CI 答"E[D] 大概率在哪个范围"；两者是同一条钟形曲线的两种量法，夹子跨零 ⟺ p>0.05。

---

## 第 1 步：配对四格表——证据只在翻题里

两臂逐题配对后，每道题只有四种命运（P2-1 vs P-a 实测）：

| | P-a 对 | P-a 错 |
|---|---|---|
| P2-1 对 | 251（都对） | **b=36**（只有 P2-1 对，"翻上"） |
| P2-1 错 | **c=28**（只有 P-a 对，"翻下"） | 185（都错） |

436 道"都对/都错"的题两臂表现一样，对"谁强"零信息量，相减抵消——**证据全部在 64 道翻题里**。
自检不变量：b−c 必等于两臂对题数之差（287−279=8=36−28），对不上=账有错。

## 第 2 步：定义随机变量 D 与目标量 E[D]

每道题记 D = +1（翻上，36 题）/ −1（翻下，28 题）/ 0（其余 436 题）。
样本均值 = (b−c)/n = (36−28)/500 = **+1.6 个百分点** —— 这就是报告里的 Δ。
我们真正想知道的是 **E[D]（题目总体上的真实平均差）**——一个看不见的数；p 和 CI 都是对它的推断。

## 第 3 步：随机性从哪来（决定性系统下的关键一层）

我们的运行是决定性的（greedy、seed 固定、batch-invariant）：**同一道题重跑一万遍，D 不变**。随机性不在模型身上，而在"这 500 道题是题目总体的一份抽样"：

- **CI 的随机观**：换一批 500 题，均值会晃——CI 量的是"换题晃动"，夹的是总体真值 E[D]；
- **p 的随机观**：零假设世界里每道翻题的**符号**是公平硬币——p 操纵这个假想随机；
- 推论①：同批题重跑零信息量，加功效只能**换题/加题**（这就是加测第二个 benchmark 的统计学动机）；
- 推论②："+1~+3 且 n.s."一族结果 = 效应被换题晃动（SE≈1.6 分）淹没，不是"效应不存在"的证明。

## 第 4 步：p 值——运气律师的辩护成功率

**假想世界（无罪推定）**：两臂真实水平完全相同 → 64 道翻题各掷一枚**全新的公平硬币**（注意：不是从 36:28 里有放回抽样——那是 bootstrap，回答 CI 类问题，方向相反）。

**公平 ≠ 对半**：掷 64 枚公平硬币正好 32:32 的概率只有约 10%；结果天然散成以 32 为中心的钟形。分布长这样（102 枚硬币版的实算示意）：

```
 b=45   3.91%  ███▏        ← 左尾起点
 b=51   7.88%  ██████▎     ← 正好对半（最高也只有 7.9%）
 b=57   3.91%  ███▏        ← 观察值
两条尾巴（≤45 或 ≥57）面积之和 = 27.6% ← 这就是 p
```

**p 的定义与实操**（三行算术，不跑任何实验）：

```
p = Σ C(64,k)/2^64,  对所有 k>=36 或 k<=28 求和 = 0.3817
```

等价的笨办法：用随机数真掷 64 次×10 万场，数"至少和观察一样偏"的场数比例（实测 0.375≈公式值）。McNemar"精确检验"的精确=用组合数逐种情形数清楚。
**读法**：p=0.38 → 纯运气三场里有一场能复刻这份证据 → 辩方成立率太高，不立案。判案门槛 α=0.05 开跑前冻结。

## 第 5 步：95% CI——夹真值的夹子

三步手算（吃 b、c、n 三个数）：

```
均值      = (36−28)/500                =  +1.6 个百分点（点估计,定中心）
单题方差  = (36+28)/500 − 0.016²      ≈  0.128
标准误 SE = sqrt(0.128/500)           =  1.60 个百分点（定步长）
95% CI    = +1.6 ± 1.96×1.60          =  [−1.5, +4.7]（1.96 步定夹宽）
```

口诀：**均值定中心，标准差除以根号 n 定步长，1.96 步定夹宽**。除 √n 是关键——标准差量单题晃动，CI 夹的是 500 题**平均值**的真值；漏掉它夹子宽 22 倍。

**1.96 的来历**：正态曲线的几何属性——中心往两边走 z 个标准差罩住的面积：±1.0→68.3%、**±1.96→95.0%**、±2.58→99.0%、±3.0→99.7%（对 erf 反查 95% 的解=1.959964，与圆周率同性质的常数；"±2σ"是工程凑整）。单题 D 分布很丑（三值）没关系——500 题**平均值**按中心极限定理自动变钟形，才有资格引用这条曲线；95% 本身是约定（=α0.05 的另一面）。

**读法**：夹的是**真值 E[D] 这一个数**（重做百遍实验约 95 个夹子罩住真值），不是逐题差值的范围。夹子跨零 ⟺ p>0.05——同一条曲线，p 量尾巴面积、CI 量夹子宽度。

## 第 6 步：四格表定了，p 和 CI 就定了

p（精确 McNemar）只吃 (b,c)；CI 吃 (b,c,n)。代入即出、无随机成分——这是"Inspect=机械比对"的数学基础。三个补丁：①前提是检验方法已选定并预注册（换方法=第二次掷骰子）；②都对/都错两格对 p 零贡献、对 CI 只通过 n 贡献精度（b:c 同为 36:28 时,n 大 10 倍→CI 窄 √10 倍）；③表格定数字，不定数字的可信度——配对设计成立（同题/同对/同祖/判据先冻结）是拿到表之前的纪律责任。

## 三条不许误读

1. p **不是**"无效应的概率"——它是"若无效应,证据长这样的概率"，主语是证据不是效应；
2. n.s. **≠** 证明为零——可能效应太小功效抓不住，只写"分不清"（47:47 完美对称除外）；
3. 门槛 0.05 **事先冻结**——看到 p=0.06 现场放宽=收买法官（实验卡预注册防的就是这个）。

## 附：本项目实际用的两条公式（伪代码）

```python
# 精确 McNemar 双侧 p
m = b + c
p = min(sum(comb(m, k) for k in range(min(b, c) + 1)) * 2 / 2**m, 1.0)

# 配对差 95% CI（百分点）
delta = 100 * (b - c) / n
half  = 196 * sqrt(b + c - (b - c)**2 / n) / n
CI    = [delta - half, delta + half]
```
