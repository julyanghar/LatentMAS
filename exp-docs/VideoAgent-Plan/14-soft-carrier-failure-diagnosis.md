# 14 · 软载体（概率/latent）全阴的诊断角度目录

> 2026-08-09。回答"为什么概率/latent 不好——除了熵，还有哪些诊断角度"。
> 三个角度已用现有数据出数（A/B/D），其余为设计就绪的候选诊断（含成本与预期）。
> 主判决出处见 [13 三联档](13-conclusions-evidence-arm-deltas.md)；本档只管"为什么"。

**TL;DR**：免训练软通道的死因不是单一的"没信息"。实测拼图是——发端大多数位置确实无话可说（中位熵 0.14-0.26 bit），但**有话的地方说的是任务相关的真话**（动词位 1.98 bit，候选=holds/places/looks 这类动作分歧）；这些真话传过去仍无分（P2-1 +1.6 n.s.）→ **矛头指向收端**：未经训练的接收方把软输入当最近的硬 token 读，流形外的分量只起扰动作用（CL 翻题 140 净 0）。adapter 的机制论证=训练收端听懂。

## 已出数的角度

### A. 发端信息量（熵账本）

两本书全部 top-64 npz，抽 50 视频（8.4 万/9.8 万位置）：

| | 8B 书 | 30B 书 |
|---|---|---|
| 每位置熵（中位） | 0.14 bit | 0.26 bit |
| p1（第一候选概率，中位） | 0.98 | 0.96 |
| p1>0.99 位置占比 | 47% | 41% |
| 有效候选数 2^熵（中位） | 1.10 | 1.20 |

读法：多数位置分布≈独苗，Σp·E≈0.98×one-hot——**"概率载体"在大多数位置上数值≈文字**。整句 caption 的额外信息 ~2 bit。

### B. 信息在哪、是什么（位置×语义分析）——修正简单版叙事

30B 书按句内位置的熵分布（位 0-9 均值）：

```
位0(主语"C"): 0.00 · 位1(动词): 1.98 ← 熵的家 · 位2: 0.50 · 位3: 0.87 · 位4: 0.99 · 之后衰减
```

高熵位置（>1 bit）的 top1/top2 实例：' holds' vs ' places'（0.53/0.12）、' looks' vs ' places'、' rod' vs ' pipe'——**真语义分歧而非同义词/标点**，且动作歧义正是 EgoSchema 的主要考点。
**含义**：发端不是完全没话说——它在动词上如实报告了犹豫，这些犹豫是任务相关的；软通道把它们传了（P2-1 逐调用注入核实），仍 +1.6 n.s. → 瓶颈在收端。

### D. 动力系统角度（CIPHER 轨迹，现成 traj 文件 80 条）

逐步熵均值（bit）：

```
步0:1.85 → 步2:3.33(爆) → 步5:2.05 → 步8:0.85 → 步20:0.69 → 步47:0.45(竭)
```

先爆后竭：软反馈头几步把模型推入高困惑（熵冲 3.3），随后跌进低熵复读吸引子（0.45），与 587/587 顶满不自停、影子".2.2.2"复读互证。**单跳软自回归是一个不稳定动力系统**——CIPHER 原论文的多智能体辩论结构恰好提供了外部扰动防止塌缩，单跳没有。

## 设计就绪的候选诊断（按性价比排序）

### F. 因果替换审计（最便宜、最一锤定音）★推荐首选

CL 的 140 翻题到底是"信息"还是"扰动"：50 题三臂——CL 原样 / CL 换**乱序 latent**（打乱位置对应）/ CL 换**同范数随机噪声**。若三者翻题量与净差相当 → "纯扰动"实锤（发表的 dummy-replacement 协议，2605.18445/2607.26773 同款）。成本 ~1h。**这也是 B 臂 adapter 将来必过的验收协议，提前搭好一举两得。**

### C. 收端读取方式探针（最近邻坍缩验证）

人工构造双峰位置（如 holds/places 各 0.5）注入，扫描输出对第二峰权重的敏感度：若输出只随 argmax 翻转而对 0.5→0.1 的连续变化零响应 → Greedy Pitfall（收端只读最近 token）直接坐实。成本 ~30min（几十条构造请求）。

### E. 流形离群度（latent 专属）

量化 M 对齐后向量的"流形外能量"：与最近 token 嵌入的距离 / 词表内典型近邻距离之比；残差能量占比。预期解释"高扰动净零"（离群分量=收端眼里的噪声）。成本：sidecar 抽样重算 ~1h。

### G. 注意力利用度（最重，选做）

HF 前向取注意力，比较注入位 vs 硬 token 位收到的注意力质量（KVCOMM 分析经验可复用，见 memory）。回答"收端是忽略了软位置还是读了但读歪"。成本 ~半天。

### H. 需求-供给账（任务信息论框架，论述用）

任务缺口=像素红利 4.8 分；软通道的额外供给≈2 bit/句且集中在动词。C−D 的 +4.8 说明缺的主要是 **caption 词汇化阈值以下**的视觉细节（分布的 top-64 里根本没有的东西），不是"已词汇化候选间的犹豫"。→ 软通道即使被完美读取，供给也覆盖不了缺口——与 A/B/C 三角度共同构成完整死因链。

## 文献机制对照（外部背书）

Greedy Pitfall（收端读 argmax）· Illusion of Superposition（预训练模型叠加态塌缩）· Thought Communication（裸状态混杂共享/私有分量）· 因果审计协议（latent 收益须过替换对照）——四条批评线与我们的 A-H 逐一对应；CIPHER 单跳塌缩曲线（角度 D）未见发表，为一手观察。

## 与 adapter 的关系（为什么这套诊断值得做）

死因链"发端多数位置无话（A）× 有话处收端失聪（B+C）× 供给不覆盖缺口（H）"里，adapter 攻的是**中间一环**：训练收端读懂视觉表征。F/C/E 三个诊断同时是 adapter 的**验收协议原型**——桥训好后必须证明"过桥的是信息不是扰动"，协议现在就能定。
