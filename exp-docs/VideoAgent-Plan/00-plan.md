> **全文比喻**：一台**换管道手术**——病人（现有视频 agentic 框架）体内有一根文字管（viewer 把看到的写成 caption 传给 reasoner），手术是把它换成 latent 管，其余器官不动。

## TL;DR

1. **做什么**：在现有 VideoMAS 的 **viewer(Qwen3-VL-8B) → reasoner(Qwen3-8B) 盲文字边**上，把 caption 换成 latent。**成功标准：这个替换能涨分**（存在性主张；不要求打赢所有替代方案）。
2. **执行顺序（用户裁定）**：阶段 0 资产 → **阶段 1 五条免训练臂全跑（A/T+/D/C/A′ × 两库各 500 题）** → **阶段 2 压轴：adapter + B 臂 + D0 探针** → 阶段 3 加固。全 HF。⭐ 死刑条款 C−D/A−D 在阶段 1 触发——**判死先于 adapter 投入**。
3. **实验骨架 = 信息阶梯 `A(one-hot) < T+(分布) < B(latent)`**；死刑条款只有两条：C−D≈0（文字管不漏）、A−D≤0（文本脑不占优）。

## 1. 我们要做什么

```
                     ┌─────────────────────┐
   视频帧 ──────────► │ viewer = Qwen3-VL-8B │
                     └──────────┬───────────┘
                                │  ⭐ 手术位置：latent，不是 caption
                                ▼
                     ┌──────────────────────┐
                     │ reasoner = Qwen3-8B   │ ──► 决定下一批看哪几帧 / 出答案
                     └──────────────────────┘
                                │  循环（取帧请求保持文字）
```

**三条硬要求与依据**：

| 要求 | 依据 |
|---|---|
| ① reasoner 是**纯文本推理模型** | 三份独立证据"换脑比换通道值钱一个量级"：VideoAgent 消融（换脑 +11.4 vs 通道加宽 10.3 倍只 +0.6）· MemDreamer Table 6（换推理模型 10.0/12.1 vs 换感知 0.4~2.5；解耦后推理力相关性 R 0.702→0.897）· SportMV-Agent（换 orchestrator −10.99% vs 换感知工具 +0.41%） |
| ② 建在**已有** workflow 上 | 骨架不动、只换管道，涨跌才能归因到通道；host 用 caption 交流是**入选条件**（没有文字管就没东西可换） |
| ③ 最终在**多个**框架上有效 | 从"一个系统的 hack"变成"可插拔通道"；此线无共同 benchmark、无 head-to-head 协议 |

**前提判断**：大概率需要训练；免训练跨架构直塞不可行（§4 给证据，§3.2 γ 实验 1 小时正式判死它）。

## 2. 主张与定位

**新颖性所在（先例审计后仅存的两个合取项，详见 [01](01-prior-art-audit.md)）**：

```
(a) 发送方是会推理的 agent，不是接收方自己的感知前端
(d) 多轮循环里，纯文本接收方决定 viewer 下一步看什么
```

**先验两面都记**：有利面——VideoMAS 的 reasoner **结构性失明**（无视觉塔），适用先验是 C1 盲文字臂 **Latent−Text(blind) = +15.8/+11.4/+17.3/+12.3**（打折条款：那是同模型 KV、无跨模型翻译损失，属上界味先验）+ MACF +13.7~18.6、LACO 单调——**不对称设定正是文献里 latent 赢的那半**。不利面——(d) 的邻居格都不高（"语言决策+caption"最好 43，"隐状态+浅层读出头"21.46），我们那格无人测过。

### 2.1 成功标准

> **对现有 VideoMAS，只要 viewer-VLM ↔ reasoner-LLM 之间"文字→latent"的替换能涨分，即证明方法价值。**（主张形状先例：Latent Bridge *"never significantly worse … significantly better on K of N"*，带代码发表。）

**卖点排序**：

1. **主**：盲文字边上换 latent 的**准确率增益**
2. **副**：效率（省 caption 生成 + 不重编码已看帧；全部工作后置，见 §2.2）
3. **底线**：若增益≈0 但效率大赚 → 退回"同分省算力"的帕累托表述——两扇门实验设计天然同时覆盖

**C 臂的角色 = gap-closure 分母**：报 `(B−A)/(C−A)`（文字→像素的差距里 latent 补回几成）。C 赢不判死——"坚持文本脑"有 §1① 三份证据 + LinguDistill（VLM 化伤语言力）支撑。

### 2.2 当前优先级

- **近期里程碑**：阶段 1 的 **T+−A**（免训练）；**最终里程碑：B > 基线（A 或 T+ 取高者）**——adapter 及其探针压轴（阶段 2）。
- **首胜实验只保留两个前提**（它们不是加固项，是"比的是通道"这句话成立的条件）：① **统一 viewer**——A 的 caption 与 B 的 latent 同出 Qwen3-VL-8B；② **零向量对照**——latent 换全零/随机再跑一遍，防自欺，成本一次推理。
- **后置项**（阶段 3）：全格报告、CAG、双尺寸接收方、VideoHV 第二 host、NExT-QA 扩全量、**效率账全套**（vLLM 迁移、prompt_embeds 吞吐、SPARC 对比）。
- **诊断包**：D0 探针族与 C−D/A−D 不再挡在开发前——**B 首败时再逐级定位输在哪**（B 输不判死，可能只是 adapter 没训好）。γ 随时可跑。
- **判读不对称性**：B 赢=信息量大（头条到手）；B 输=信息量小（进诊断包）。
- **已接受的风险**：若文字管其实不漏，adapter 的 ~10 GPU·h 与 2 天工程白费——用它换最快的核心信号。

## 3. 实验设计：对照臂与诊断体系

### 3.0 诊断探针总览

| # | 探针 | 检验什么 | 成本 | 要 adapter 吗 |
|---|---|---|---|---|
| **D0-a** 复述 | reasoner 能凭 latent 复述帧内容吗（含 caption **没有**的细节）？不能 → 看不懂，换桥 | 小时级 | ❌ |
| **D0-b** 示范 | 给 1~2 道 in-context 示范后 latent 臂追上 caption 臂吗？追不上 → 信息没传到 → 止损 | 小时级 | ❌ |
| **D0-c** 单调性 | latent−caption 的 gap 随训练单调缩小吗？不缩 → 训练目标错 | 训练中监控 | ✅ |
| **D0-d** 反解阶梯 | 伪 token 信息能否被文字装下（hard=最近词 / soft=`softmax(e·Eᵀ/τ)·E` / raw=原样；用**输入嵌入矩阵**，先查 `tie_word_embeddings`，τ 要扫） | 半天 | ⚠️ 粗训即可 |
| **γ** | 免训练直塞 KV 行不行 | 1 GPU·h | ❌ |
| **重构上界** | m=32 向量装得下一帧 caption 级信息吗 | 半天 | ❌ |

**探针排期（用户裁定：全做，adapter 系压轴）**：D0-a/b/c/d 与重构上界的体检对象是 adapter 的伪 token——**随 B 臂放阶段 2**；**γ 免训练，阶段 1 内随时插**。⭐ 顺序副作用：**死刑条款 C−D/A−D 在阶段 1 触发——回到了 adapter 前面**，若判死则压轴阶段整体取消，一分卡时不浪费。

D0 四级的病理学：**没传到→止损；看不懂→换桥；不会用→可训练**——三种病三种药，先分清再动手。D0-d 判读：

```
raw ≈ soft ≈ hard   →  文字装得下 → 通道优势是假的 → 止损
raw ≈ soft ≫ hard   →  信息在叠加权重里 → 优势真，但 CIPHER 级通道可能就够
raw ≫ soft          →  信息在词嵌入凸包之外 → 「超语言」最强证据
```

### 3.1 六臂对照

所有臂共用 host 原生循环（VideoAgent 版细节见 [05 §2](05-videoagent-workflow-source-analysis.md)），唯一差别是 **reasoner 收到什么**。**六臂全做**：五条免训练臂在阶段 1，B 臂随 adapter 压轴（阶段 2）：

| 臂 | reasoner | 收到 | 阶段 |
|---|---|---|---|
| **A** 现状 | Qwen3-8B | caption 纯文字（one-hot） | **首胜** |
| **T+** 软文字 | Qwen3-8B | **与 A 同一条 greedy caption 轨迹**，每个位置传 top-k 分布软嵌入 `Σp·E_receiver`——免训练、免 adapter、免疫漂移（p 锚在共享词表上，两家各用自己的 E 落地）。**【实测 2026-08-06 词表全等】**：vocab.json 逐字节相同、`get_vocab()` 全等（151,669 条）、caption 测试句编码逐 id 相同、视觉特殊 token 两边同 id、merges 仅差一行版本注释——**T+ 的前提条件成立** | **阶段 1** |
| **B** 我们的 | Qwen3-8B | 经 adapter 的伪 token | **压轴（阶段 2）** |
| D 控制组 | Qwen3-VL-8B（不给图） | 与 A 逐字相同的文字 | **阶段 1** |
| C gap 分母 | Qwen3-VL-8B | 选中帧的原图 | **阶段 1** |
| A′ 先知上界 | Qwen3-8B | captioner 事先知道题目写的 caption | **阶段 1** |

**减法各回答一个问题**：

```
⭐ T+ − A   离散化本身丢多少（token 骨架逐字相同，唯一变量=亚军概率质量）
⭐ B − T+   输出分布之外的信息值多少 = adapter 的存在理由
⭐ B − A    头条数字
   C − D    文字管到底漏多少（reasoner 能力控住的干净测量；≈0 → 死刑）
   A − D    文本脑比 VLM 脑强多少（≤0 → 死刑）
   C − A    换 VLM 当脑值多少（gap-closure 分母）
   A′ − A   "不知道会被问什么"造成的漏损
```

**信息阶梯**：`A < T+ < B`——T+ 比 A 多"每个位置的犹豫"（写"白狗"时"棕"的概率质量还在）；B 比 T+ 多"caption 压根没说出口的东西"（pre-readout 视觉状态）。⚠️ **T+ 与 B 无严格包含关系**：分布只在"说到的位置"泄露备选，完全没说出口的内容不经过分布——所以 T+≈A 不判死 B。

**T+ 工程钉**：top-k 稀疏（k≈64）；模板/控制 token 保持硬；单跳传输（多轮漂移警告不适用）；与 D0-d 区分（D0-d 投影 adapter 输出、T+ 传 sender 自己的解码分布）；机制先例 = CIPHER 必引，我们的贡献形态是"臂"。

**死刑条款（预先写死不得放宽）**：`C−D ≈ 0` 或 `A−D ≤ 0` → 立论崩；`A′≈A` → 预期缺口为零，重估。

⚠️ **解读 C−D 时的两个已知警示**：TAMA（唯一直测"工具返回图 vs caption"）+2.68±1.37 分不出与零；MemDreamer 纯文字图记忆比整段像素高 8.7~21.2（但混淆了通道与上下文预算——我们的 C−D 控住预算，才是干净版）。

### 3.2 实验 γ：1 小时判死免训练

```
数据：GSM8K 200 条纯文本提示（对免训练最有利情形）
A 参照：Qwen3-8B 自己 prefill 自己解码
B 朴素：Qwen3-VL-8B 无图 prefill 同一提示 → dump 逐层 K/V → 装进 Qwen3-8B 解码
C 修复：同 B + key 按 5e6 反旋再按 1e6 重旋
判死：B 崩且 C 救不回（top-1 < 90%）→ 免训练路线关闭
```

价值："我们测了，免训练不成立"是论文可写的一段，且只花 1 GPU·h。

## 4. 为什么必须训练

> 比喻：交接班留一本工作笔记，需要**本子插得进去（形状）、页码对得上（位置）、字认得出（内容）**——实测前两件过，第三件不过。

### 4.1 本机漂移探针

| # | 探针 | 结果 | 白话 |
|---|---|---|---|
| ① | KV 几何 | ✅ 36 层/4096/8 KV 头/head_dim 128 全同 | 本子插得进去——这条路值得试的原因 |
| ② | M-RoPE vs 1D | ✅ diff=0.0 | 伪问题：文字 token 三轴精确退化成一维 |
| ③ | rope_theta 5e6 vs 1e6 | ❌ 位置>64 退相关（cos 0.713） | 确定性可修（反旋+重旋），不用学 |
| ④ | k/v_proj 漂移 | ❌ 15–27%（自身后训练漂移的 2.3–2.7 倍，随层加深） | ⭐ 真正的坎：同一符号两家心里不是一个意思 |
| ⑤ | 端到端 | ❌ 第 0 层 V-cache 误差已 31.9% | 最浅层就三成，后面还有 35 层 |
| ⑥ | chat 控制符 | ❌ 漂 54%/57%（普通 token 16–20%） | 最需对齐的结构支架处误差最大 |

**三条补充**：漂移量级已超 DroidSpeak 测的"朴素复用掉 >50% 准确率"区间；**位置修好也不够**（ChronoStitch：同模型内位置修到机器精度、顺序探针反而 41.7%，需重算 25~35% token——"positions are necessary, but not sufficient"）；文献 4/4 同测两者的论文里**训过的全面吊打免训练**（MACF +4.7~8.3 / DiffMAS +20 / HyLaT / VW 弱监督转负）。

## 5. adapter 设计与训练

### 5.1 要解决三件事

| # | 问题 | 现状 |
|---|---|---|
| 形状 | 能否直接装 | ✅ 免费（§4①） |
| 位置 | rope 底数不同 | ⚠️ 反旋+重旋可修，但必要非充分 |
| ⭐ 内容 | reasoner 没见过视觉向量 | ❌ **唯一需要学的** |

### 5.2 注入点：输入层伪 token

(i) 逐层 KV 前缀与 (ii) 加性融合在纯文本接收方上均无先例（前 0..l−1 层没参与生成那些 K/V）；**(iii) 输入层伪 token 有 BLIP-2/LLaVA/Frozen 大规模验证——选它**，让 reasoner 用完整 36 层消化。

两条附带纪律：**验收必须有端到端臂**（Latent Bridge 教训：中间层 cross-attn 离线 KL=0.004 却上线崩）；效率论证的正确表述是"**根本不生成文字**"（decode 比 prefill 贵 92 倍：10.46 vs 0.114 ms/token@8B）而非"跳过层"。

### 5.3 读料：双轴扫描

**载体**（进 reasoner 的形式）= 输入层伪 token m≈32——与 NavGPT-2/Latent Bridge/BLIP-2 同款，**不承担新颖性**。
**读料**（从 viewer 取什么）= 扫描超参：

- **层深** `{浅 4–10 / 中 12–24 / 末层 / 多深度}`，**先验偏中层**（ViF drop study：丢中层关键子集 −59.9 最致命、丢深层仅 −2.6~−3.4；Latent Bridge 读 24/36、MACF 读末层，无人读浅层。LACO"浅层最优"是载体=KV 直塞时防劫持的结论，约束不到读料）
- **形式** `{V-only, K+V, h}`（K、V 各 1024 维是 h 的有损投影，读 h 信息不亏；K 被 RoPE 旋过而 V 没有——优先读 V 或先反旋 K）

### 5.4 输出头：两个变体平级对比

```
主干：m 个可学 query → cross-attend 读料 → 2~6 层小 transformer(d=512) → 投到 4096
参数 ~21M，约 5 GPU·h 一次配方
```

| 变体 | 输出 | 一句话 |
|---|---|---|
| **A 自由向量** | m 个任意 4096 维向量 | 表达力无上限；但落在 reasoner 没见过的区域 |
| **B 软词瓶颈** | `softmax(h·Eᵀ/τ)·E`（E=reasoner 冻结词嵌入，零新增参数） | 消息强制为母语词嵌入概率加权和 = trained cross-modal CIPHER：天生在流形上 + 可解释性白送 |
| 判读 | A≈B → 选 B（白送可解释性）；A≫B → 差值=超语言信息的实测大小，本身是主图 | |

B 的监控清单：熵塌缩（τ 要扫）、范数收缩（凸组合往均值拉，必要时加可学增益）。软词瓶颈是前向参数化不用对 E 求逆；D0-d 的事后投影只是它的下界（训练后量化 vs 量化感知训练）。

### 5.5 训练：两段课程

> 📌 **通俗版——三个角色一个故事**：📷 摄像师（viewer，冻结）看帧有印象；✍️ **翻译员（adapter 21M，全场唯一在学）**把印象写成 32 张密文便签；👴 老师（reasoner，冻结）只会读字。**核心机制：冻结 ≠ 不传梯度**——扣分不改老师，但"在第几张便签读岔的"这条批改意见穿过老师传回翻译员。
> **第一课 = 软蒸馏听写课**：老师只看便签逐字念 caption，判分不是"词念对没有"，而是**每个位置念出的候选概率要贴近摄像师写时的犹豫**（它 55% 想写 draws、20% 想写 sketches，老师也该有同样的摇摆）。软判分的两个好处：批改信息从 1 比特变整张分布（KD 软标签>硬标签）；**天花板从 caption 印刷体（A 级）抬到叠影字（T+ 级）**，留给第二课去破。
> **第二课 = 防串卷考试**：拿对便签要答好、**拿别题便签要答不出**（负样本=同 batch 互串，白送）——因为实测过 +10 分里 +8 分是"塞别题便签也能涨"的安慰剂，串卷在训练里掐死它；辅以答案对错。
> **缺一不可**：只上第一课=只会写得让人读懂，不会写对考试有用的（Sterner 的桥就这么输了 4.5）；只上第二课=老师连便签都不认识，信号稀薄学不动（MACF 去掉第一课 −14.9）。**顺序即药理：第一课治"看不懂"，第二课治"不会用"。**
> **三条纪律**：练习册（NExT-QA train）与考卷（EgoSchema 整套）分开，背题=作废；摄像师印象提前拍照存盘、上课不到场；墙上挂体温计（D0-c），500 步差距不缩就换配方。


| 段 | 信号 | 说明 |
|---|---|---|
| **一：软蒸馏锚定** | reasoner 凭伪 token 念出的**逐位分布**贴近 viewer 的逐位 top-k 分布（KL） | 软标签>硬标签（经典 KD）；天花板=T+ 水平（不是 caption）；锚定本身必要（MACF：去掉 Stage1 −14.9） |
| **二：对比式为主 + 行为式为辅** | 正=本题 latent、负=**batch 内别题 latent**（负样本白送）；辅以答案 CE（可升级 Mem-W 式 RLOO） | 对比式把"安慰剂检查"烧进训练目标（因果审计：+10pp 里 +8.13pp 在换成别题消息时仍在）；只上第一段必败（Sterner 的桥只训 captioning、VQA 输 4.5） |

**训练力学**：

- **冻结 ≠ 不传梯度**——损失穿过冻结 reasoner 36 层流回 adapter（BLIP-2/Frozen/Sterner 同款）；两端 8B 全冻，只有 21M 在学。
- **读料离线化**：冻结 viewer 的确定性输出，离线算好存盘——训练时 viewer 不驻卡，单卡可训。
- **数据**：一段 =（帧，caption+逐位分布）对，离线资产直接复用（EgoSchema 9 万对起步）；二段 =（帧，问题，答案），**只用 NExT-QA train**。
- ⚠️ **数据泄漏红线**：EgoSchema 仅 subset 500 题带答案，**严禁用于训练**——NExT-QA train 训 → NExT-QA val 测 + EgoSchema 整库纯测试（跨库泛化）。
- **预算**：~5 GPU·h/配方 × 两变体 ≈ 10 GPU·h；监控：D0-c 单调性（500 步不缩杀配方）+ B 变体的熵/范数两表。

## 6. Host 与模型名册

### 6.0 模型名册（全计划唯一权威）

**两条总则：所有文本 LLM 角色 = Qwen3-8B；所有看图角色 = Qwen3-VL-8B。**

| 角色 | 钉定 |
|---|---|
| VideoAgent 大脑 · VideoHV 出题人/判官/选答人/验证员 · 摘要重生成 | **Qwen3-8B** |
| VideoAgent captioner · VideoHV caption 工具 · 六臂中的 D/C/A′/B viewer | **Qwen3-VL-8B**（看图写话必须 VLM） |

**配套决定**：

1. Qwen3-VL-8B 用 **Instruct** 变体（与现役铁律 backbone、C1、漂移探针同款）。
2. Qwen3-8B 的 thinking 开关（混合思考模型，非独立 checkpoint）**由 H2/H3 spike 各跑 on/off 两档定**，按格式存活率+准确率择一后全程统一。

### 7.1 分阶段

| **0** | H1 + H2 + **EgoSchema 全 500 视频抽取→抽帧→caption 用 Qwen3-VL-8B 重生成（同一遍 dump 逐位 top-k 分布）** + NExT-QA 视频源调研 | ~1-2 天（抽视频可过夜） | 五臂资产就绪 |

### 7.1.1 样本量与训练数据（2026-08-06 定）

**评测（六臂同题配对）**：

| 库 | 量 | 依据 |
|---|---|---|
| EgoSchema | **全部 500**（subset 即上限，fullset 答案不公开） | 全量即配对功效最大 |
| NExT-QA val | **先 500 分层抽样**（按 C/T/D 题型比例、ATP-hard 2269 占约半），阶段 3 扩全量 **4,996**【本地资产实核：4996 题/570 视频】 | C1 先例 n≈800 分辨 2~3pp → **500 分辨 ~3-4pp**，够判目标效应 |

**抽样三纪律**：题单一次抽定 + seed 写死 + **六臂共用同一份题单**；按题型分层（§7.2-4 的前提）；ATP-hard 可单独出表（难题上通道差异才拉得开）。

**训练数据（阶段 2 用，起步量写死、扩容看 D0-c）**：

| 段 | 数据 | 起步 | 可用池 | 扩容条件 |
|---|---|---|---|---|
| 一（软蒸馏） | NExT-QA **train** 帧-caption-分布对 | **50k**（≈1 epoch） | ~170k（3,870 视频×~44 帧）【H1 核】 | D0-c 仍在降 |
| 二（对比+行为） | NExT-QA **train** QA | **10k**（2 epochs） | ~34k【H1 核】 | 配方定型后扩全量 |

预算自洽：5 GPU·h/配方 ≈ 4~7 万样本前反向，50k+10k×2 装得下；两变体 ×2 ≈ 10 GPU·h。**EgoSchema 帧一律不进训练（连 Stage 1 都不进）——纯考场。**

### 7.1.1 推理栈纪律

**同栈原则**：会互相减的数字必须同一推理栈。**分界口诀：这个数字会不会和另一个数字相减？会 → 同栈（HF）；不会 → 哪个快用哪个。**

- **对比臂推理（A/T+/B 及此后所有进表的臂）**：全 HF；内部统一 attention 实现（flash-attn/sdpa 二选一）+ bf16 + greedy + 固定 seed。B 臂 reasoner 用 `generate(inputs_embeds=…)`。
- **离线资产制作**（caption/摘要重生成、抽帧）：vLLM 批量——所有臂共享同一份输入，制作栈差不进对比。
- **工程冒烟**（H3 spike）：vLLM——测的就是它自己。
- **效率账（2a）**：两臂都迁 vLLM；B 走 `--enable-prompt-embeds` + completions 端点收 bytes 张量（本机 vllm 0.18.0 已核实支持，chat 模板自己套），A 也走 completions 对齐代码路径。
- **viewer 读料**：h 走 HF `output_hidden_states`；KV 可走 LMCache 连接器。adapter 训练必然 PyTorch/HF。

### 7.2 评测纪律（加固期全套）

1. **CAG 进主表**：本题 latent − 别题 latent；对照臂 = 零消息/随机/shuffle/caption/C 上界。
2. **桥替换对照**：latent 换全零/随机看分数变不变（首胜期就做，唯一提前的一条）。
3. **≥2 个尺寸接收方**（+Qwen3-4B）：因果审计的结论在 4B/8B 间会反转。
4. **按题型分层报**：通道价值取决于题型（简单感知题上多绕一道帮倒忙），只报总分会被单格拖垮。
5. **解析失败率单独报**：两 host 都有"解析失败→random 答案"兜底，不拆开污染臂间对比。
6. **效率账对手是 SPARC**（不是"全量重编码"稻草人）；仅存差别 = crop/zoom 每次重看要重过视觉编码器、KV 复用不过（Kamera：230ms vs ~5ms）——墙钟+显存+吞吐三口径实测。

## 8. 写论文的红线

### 8.1 三句不能说的话

1. ❌ "没人做过视觉→latent→冻结纯文本 LLM"——Frozen/BLIP-2 谱系占满，NavGPT-2 连循环都做了。只能 claim (a)+(d)。
2. ❌ "文字带宽不够 / latent 本质更保真"——Latent Bridge 自己否掉 bandwidth story；Sterner caption 赢 4.5；LimitsOfText 证明文字丢的 88% 特征主要是表层形式。**"在盲 reasoner 人群上实测涨分"是经验结果，可以说；"latent 本质更保真"是机制前提，不能说。**
3. ❌ Vision Wormhole 的 off-manifold 段落当"领域认为不可能"——五年前就被实验解决。

### 8.2 必须正面引的先例（一句话版，详见 [03](03-eight-risk-papers-explained.md)）

**CIPHER**（传分布机制的原创，T+ 必引）· **Latent Bridge**（F/T/L 三臂同款，接收方是 VLM）· **Mem-W**（五占四，差的只有模型边界）· **NavGPT-2 + Sterner**（占掉 P1+P2+P3+循环 / 占掉 caption-vs-latent 对照）· **LinguDistill**（唯一逐层 KV→冻结文本 LM，同架构仅训练时）· **ChronoStitch**（mRoPE 重定基模型内先例）· **SeeingEye/BeMyEyes**（文字通道版强基线）· **SPARC**（效率对手）· **MemDreamer**（motivation 最强反例，靠控预算的 C−D 回应）。

### 8.3 六条设计硬约束

| # | 约束 | 出处 |
|---|---|---|
| 1 | 免训练版只当故意报告的负结果跑一次（γ） | 4/4 论文训过的吊打免训练 |
| 2 | **混合通道**：细文字控制通道（取帧请求+答案）+ latent 只装感知载荷；双通道必须训练时同时在场 | HyLaT −6.65（文字是 semantic anchor）；Latent Bridge 双通道打架 −96% |
| 3 | 载体若改 KV 直塞，只传浅层 | LACO 全深度最差（仅适用载体=KV，约束不到读料） |
| 4 | 第一段软蒸馏锚定，第二段必须换任务信号 | MACF Stage1 −14.9；Sterner 只训 captioning 则 VQA 输 |
| 5 | 文字基线用 SeeingEye/SportMV 强度原样跑 | 防稻草人指控 |
| 6 | 评测纪律 §7.2 全套 | 因果审计 |

**白送的评测切片**：BeMyEyes 主动丢弃"视觉信息太复杂、文字传不过去"的样本——那批就是我们最好的测试集。
**真空的三份独立证据**（related work 用）：39 篇视觉 KV 穷举全是模型内 · Beyond-Tokens survey 仅 VW 碰视觉且全文字任务、"multi-round/feedback" 0 次 · C2C 把两半都写进 future work。
